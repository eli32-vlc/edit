# 新增星标 ⭐ {#stars-added-⭐}

- 在壁纸中推荐了 [WallWidgy](https://fmhy.net/system-tools#wallpapers)，极简壁纸合集，似乎很受大家欢迎，桌面端和移动端均有选项。

- 在 PDF 搜索中推荐了 [OceanofPDF](https://fmhy.net/reading#pdf-search)，书库庞大，下载快速，允许用户请求缺失的书籍。

- 在动漫流媒体中推荐了 [Animetsu](https://fmhy.net/video#anime-streaming)，服务器非常快，支持自动播放 / 自动播放下一集，界面简洁。

- 在日漫网站中推荐了 [Mangadot + OniSaga](https://fmhy.net/reading#manga)，两者都有令人印象深刻的界面、庞大的书库和不错的功能。

- 在隐私索引中推荐了 [Awesome Privacy](https://fmhy.net/privacy#privacy-indexes)，专注于隐私的替代方案合集，界面美观。

- 在身体健康版块中推荐了 [Insomnia 指南](https://fmhy.net/misc#physical-health)，内容深入，引用了所有来源，广受好评。

- 在音乐探索中推荐了 [RYM Charts](https://fmhy.net/audio#music-discovery)。我们已在追踪网站中推荐了 RYM，但其可自定义的榜单也使其成为发现新音乐的最佳方式之一。你可以通过非常深入的筛选选项创建[任意数量的榜单](https://i.ibb.co/Ft5NNJJ/image.png) / [2](https://i.imgur.com/dsT6H2V.png)。

- 在演唱会 / 现场演出中推荐了 [bootleg.fm](https://fmhy.net/audio#concerts-live-shows)，社区驱动的盗录演唱会录音档案，组织良好，涵盖众多艺人，且正在持续开发。

- 在 SVG 图标中推荐了 [SVGL](https://fmhy.net/storage#svg-icons)，不错的 SVG 公司 + 程序图标库，似乎很受大家欢迎。

- 在语言学习推荐了 [Omniglot](https://fmhy.net/educational#language-learning)，深入详尽的写作系统和语言百科。

- 在 iOS 社交媒体应用中推荐了 [Swiftgram](https://fmhy.net/mobile#social-media-apps-1)，功能丰富的 Telegram 客户端，开源，且可在 Apple 官方应用商店获取。

- 在购物版块中推荐了 [Fragrantica](https://fmhy.net/misc#shopping)，全面的香水数据库，支持数据可视化、用户投票、收藏追踪等。

- 在免费字体中推荐了 [wFonts](https://fmhy.net/text-tools#free-fonts)，界面美观，字库庞大，会标注任何潜在的许可证。

- 将 AB Download Manager 移至下载管理器第 1 位，因为它开源，且效果与 jdownloader 相当（某些情况下更好）。

# 已移除内容 {#things-removed}

- 移除了 GenP，因为他们[即将停止运营](https://i.ibb.co/yFqkGHp1/image.png) / [2](https://i.imgur.com/4B2QKCa.png)。感谢他们的团队多年来的辛勤工作。 

- 移除了 Myrient，因为它[现已正式关闭](https://i.ibb.co/pB0My03B/image.png) / [2](https://i.imgur.com/9g3x9Ad.png)。愿它安息，我们会深深怀念它。感谢他们的团队长期运营。

- 移除 NekoGram，并将其加入我们的不安全列表，因为它似乎通过[隐藏后门](https://x.com/sotanews/status/2039652946233688273) / [2](https://thebadinteger.github.io/nekogram-phone-exfiltration/) 将用户的账号电话号码发送给他们的一个 TG 机器人。其开发者声称并无恶意，但情况很可疑，因此我们目前选择谨慎处理。

- 移除 BlockTheSpot，因为该项目已归档。

- 移除 Soft98 和 DownloadHa，因为两者都已无法正常使用。我们会持续关注，若将来任一恢复可用将重新添加。

- 停用 FMHY FreshRSS 实例，因为遗憾的是[我们已无法](https://i.ibb.co/ymgS7b6n/image.png) / [2](https://i.imgur.com/yd95YDd.png) 继续运行它。该实例将于 5 月 1 日关闭。 

- 将官方模型站点中的 Grok 标记为未推荐，因为免费用户的额度限制越来越苛刻（他们正试图推动用户转向付费方案），并且主动封禁许多电子邮件域名，包括临时邮箱使用的域名。他们还取消了一些功能，并降低了免费用户可用的模型版本（以前可获得 4 个 expert 4.20，现在只能获得 1 个 expert 4.20）。（来自 kiri）

- 将 Arena 标记为未推荐，因为他们[移除了一些较好的模型](https://i.ibb.co/rfLx1jFT/image.png) / [2](https://i.imgur.com/4Q1zv3m.png)。
