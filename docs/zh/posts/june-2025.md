# Wiki 更新 {#wiki-updates}

- 现在可以使用 [Brave Goggles](https://github.com/fmhy/bookmarks?tab=readme-ov-file#goggle) 搜索 FMHY。

- 为 ROMs 添加了 [Nintendo](https://fmhy.net/gaming#nintendo-roms)、[Sony](https://fmhy.net/gaming#sony-roms) 和 [Resource](https://fmhy.net/gaming#rom-resources) 板块。

- 为 Puzzles 添加了 [Rubik's Cube](https://fmhy.net/gaming#rubiks-cube)、[Minesweeper](https://fmhy.net/gaming#minesweeper) 和 [Crossword](https://fmhy.net/gaming#crossword-puzzles) 板块。

- 为 Educational 添加了 [Game Learning](https://fmhy.net/educational#game-learning) 板块，包含 [Rubik's Cube](https://fmhy.net/educational#rubiks-cube) 和 [Chess](https://fmhy.net/educational#chess) 子板块。

- 为 Internet 添加了 [Firefox Tools](https://fmhy.net/internet-tools#firefox-tools) 板块。 

- 为 Privacy 添加了 [Data Breach Monitoring](https://fmhy.net/privacy#data-breach-monitoring) 板块。

- 为 System Tools 添加了 [Task Automation](https://fmhy.net/system-tools#task-automation) 板块。

- 在 Linux 底部添加了 [Unix-Like](https://fmhy.net/linux-macos#unix-like) 板块。

- 为 [Remote Torrenting](https://fmhy.net/torrenting#remote-torrenting) 的描述添加了大小限制和注册要求。

- 根据[投票结果](https://i.imgur.com/2FOFOth.png)重新整理了 [Android Audio Players](https://fmhy.net/mobile#android-audio-players)。四个推荐项现为：Poweramp、Musicolet、VLC 和 foobar2000。

- 根据[投票结果](https://i.imgur.com/OE8zsC0.png)重新整理了 [Android Keyboards](https://fmhy.net/mobile#keyboard-tools)。FUTO 保住了榜首位置，Heli 的排名大幅上升。

- 重新整理了 [Live Sports](https://fmhy.net/video#live-sports)，移除了播放器失效或重复的站点，并推荐了几个表现突出的站点。[修改前后对比](https://i.imgur.com/eDioF9L.png)。

- 重新整理了 [Radio Streaming](https://fmhy.net/audio#radio-streaming) 和 [Internet Radio](https://fmhy.net/audio#internet-radio)，添加了新的推荐项和标签，并将两个板块移出存档区。

- 重新整理了 [RSS Readers](https://fmhy.net/internet-tools#rss-readers)，改进了标签，并移除了质量较差的项。[修改前后对比](https://i.imgur.com/oAVEC6H.png)。

- 重新整理了 [Text Adventures](https://fmhy.net/gaming#text-adventures)，添加了标签，并移出存档区。[修改前后对比](https://i.imgur.com/JrdEDC3.png)。

- 重新整理了 Dev Tool Sites，移出存档区，并拆分为 [Indexes](https://fmhy.net/developer-tools#dev-tool-indexes) 和 [Online Toolkits](https://fmhy.net/developer-tools#online-toolkits)。[修改前后对比](https://i.imgur.com/JyJOW9v.png)。

- 更新了[评分标准第 4 条和第 5 条](https://github.com/fmhy/FMHY/wiki/Stream-Site-Grading)，以奖励在所有服务器上都能正常使用源自动切换和自动播放下一集的站点。同时将画质、字幕和媒体类型标准合并到第 1 条以简化评分，并开始为共同观看功能加分。这减少了推荐项总数，也让最佳站点更加突出。[修改前后对比](https://i.imgur.com/omYr1pQ.png)。

# 新增推荐 ⭐ {#stars-added-⭐}

- 在 Image Gen 中推荐了 [LMArena](https://fmhy.net/ai#image-generation)。模型优秀、不限次数、无需注册；如遇错误请清除 cookie。

- 在 Online Chatbots 中推荐了 [HuggingChat](https://fmhy.net/ai#online-chatbots)。注重隐私、模型丰富、需要注册，但临时邮箱可用。

- 在 File Transfer 中推荐了 [Blip](https://fmhy.net/file-tools#file-transfer)。可轻松通过互联网或在自己的设备之间传输大文件。Discord 里试过的人都很喜欢。

- 在 Android Image Editors 中推荐了 [ImageToolbox](https://fmhy.net/mobile#camera-tools)。开源、功能丰富且维护良好。

- 在 YouTube Downloaders 中推荐了 [Parabolic](https://fmhy.net/social-media-tools#youtube-downloaders)。开源、跨平台，是较易用的 yt-dlp 前端之一。

- 在 Game Tracking / Databases 中推荐了 [Infinite Backlog](https://fmhy.net/gaming-tools#tracking-databases)。Backloggd/Glitchwave 的竞争者，UI 美观，支持成就集成和挑战。

- 在 Game Mods 中推荐了 [GameBanana](https://fmhy.net/gaming-tools#game-mods)。高质量、组织良好，是 Sonic、Celeste 等部分系列的首选。

- 在 Multiplayer Browser Games 中推荐 [TETR.IO](https://fmhy.net/gaming#party-multiplayer)。这是一款受欢迎的 F2P 多人俄罗斯方块，功能丰富，且由开发者[维护得很好](https://tetr.io/about/patchnotes/)。

- 在 Browser Games 中推荐 [Mario Kart PC](https://fmhy.net/gaming#browser-games)。SNES 风格的 Mario Kart，带[自定义地图](https://mkpc.malahieude.net/creations.php)和多人模式。

- 在 Android Audio Equalizers 中推荐 [RootlessJamesDSP](https://fmhy.net/mobile#android-audio)。开源，支持众多应用，支持 AutoEQ；是不错的 Poweramp 替代品。

- 在 GeoGuessr Games 中推荐 [Plonk It](https://fmhy.net/gaming#geoguessr-games)。学习 GeoGuessr 的活跃社区。

- 在 Coding AIs 中推荐 [Zed](https://fmhy.net/ai#coding-ais)。协作式编程 AI，获得了来自 [HackerNews](https://news.ycombinator.com/item?id=43959710) 和我们的成员的正面关注。
