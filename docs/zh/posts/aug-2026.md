# Wiki 更新 {#wiki-updates}

- 已添加 **[URL Search Support](https://i.ibb.co/kVdvPwnc/image.png)** / [2](https://i.imgur.com/v13FI4y.png)，现在可以搜索完整 URL 或 URL 中的文本。默认禁用，点击搜索栏中的链接图标即可启用。感谢 @Lou、@Manu 和 @Bread 促成此事。

- 为 FMHY 添加了 **[Semantic Style Search](https://search.fmhy.bid/)**，应能很好地处理自然语言。感谢 @Zenith 制作。

- 添加了名为 [Monolith](https://i.ibb.co/QjFYWTw9/image.png) / [2](https://i.imgur.com/fwZMOCw.png) 的新主题。使用 JetBrains Mono，面向 HiDPI 显示器。感谢 @Zenith 制作。

- 添加了 [RSS 风格更新日志追踪器](https://d.fmhy.bid/rss.xml)。感谢 @Zenith 制作。

- 将阅读推荐拆分为 3 个子部分：[书籍](https://fmhy.net/reading#book-recommendations) / [漫画](https://fmhy.net/reading#comic-recommendations) / [漫画](https://fmhy.net/reading#manga-recommendations)。感谢 @Dan 完成此事。

- 在视频工具中添加了 [IPTV 播放器](https://fmhy.net/video#iptv-players) 部分，感谢 @RansomQ 完成此事。

- 在社交媒体中添加了 [TikTok 工具](https://fmhy.net/social-media-tools#tiktok-tools) 部分。

- 根据 [相关投票](https://challonge.com/rtdxi8qg/fullscreen) 的结果（及讨论）重新排序了流媒体聚合器。感谢所有投票者。[之前 vs 之后](https://i.ibb.co/VYsz7PbR/Untitled.png) / [2](https://i.imgur.com/XS9RUNN.png)

- 根据投票结果重新排序了游戏 Repack 站点，感谢所有投票者。[之前 vs 之后](https://i.ibb.co/MyyqwQ6z/image.png) / [2](https://i.imgur.com/shPiyop.png)

# 新增推荐 ⭐ {#stars-added-⭐}

- 在文件托管中推荐了 [0807](https://fmhy.net/file-tools#file-hosts)，10GB，文件保留 90 天（最后一次下载后），有优秀的开发团队 + 目前反响良好。

- 在游戏下载中推荐了 [ZeiGames](https://fmhy.net/gaming#download-games)（前身为 RexaGames），资源库庞大、主机速度快、游戏更新迅速。 

- 在 ROM 部分推荐了 [LoLROMs](https://fmhy.net/gaming#rom-sites)，较新的合集，涵盖热门和小众主机，有数千款游戏 + 一键下载。

- 在游戏模组中推荐了 [Thunderstore](https://fmhy.net/gaming-tools#game-mods)，模组 + 模组管理器主要面向 Unity 游戏（但也有其他），库大，部分人更喜欢它而非 Nexus。 

- 在书籍推荐中推荐了 [StoryGraph](https://fmhy.net/reading#book-tracking-databases)，书籍追踪 / 推荐网站，功能非常丰富，部分人更喜欢它而非 GoodReads。

- 在漫画推荐中推荐了 [Comic Book Reading Orders](https://fmhy.net/reading#comic-recommendations)，海量阅读顺序目录，可追溯到 60 年代。 

- 推荐了 [The Book Prize Index](https://fmhy.net/reading#book-recommendations)，图书奖项 + 获奖图书的优质索引。

- 在优化工具中推荐了 [OptiScaler](https://fmhy.net/gaming-tools#optimization-tools)，适用于 Windows 的游戏超分辨率工具，利用游戏的运动矢量获得更好效果，没有 Lossless Scaling 那样的画面变形。

- 在影视下载中推荐了 [MKV BASE](https://fmhy.net/video#download-sites)，资源库非常庞大 + 主机质量好。

- 在动漫在线观看中推荐了 [Yeanime](https://fmhy.net/video#anime-streaming)，UI 美观、播放速度快，似乎很受欢迎。

- 在重定向绕过中推荐了 [Bypass (lc)](https://fmhy.net/internet-tools#redirect-bypass)，效果好，支持许多网站。

- 在隐私搜索引擎中推荐了 [Startpage](https://fmhy.net/privacy#search-engines)，本质上是隐私保护更好的 Google 前端，在某些情况下结果比其他隐私引擎更好。

# 已移除内容 {#things-removed}

- 移除了 Cromite，因为它现在落后 3 个主要 Chromium 版本，有许多 bug，且开发者表示正在休息，如果未来回归我们会重新添加。

- 已将 Nightcord 添加到我们的不安全列表，他们过去似乎曾被抓到[记录 Discord 令牌](https://i.ibb.co/gbG0SYhM/image.png)。注意，我们并未将其列入 FMHY，只是希望帮助传播这一信息。
