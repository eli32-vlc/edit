# 新增星标 ⭐ {#stars-added-⭐}

- 在文件托管中推荐 [0807](https://fmhy.net/file-tools#file-hosts)，10GB 空间，文件保留 90 天（自最后下载起），开发团队不错，且目前口碑良好。

- 在游戏下载中推荐 [ZeiGames](https://fmhy.net/gaming#download-games)（原 RexaGames），库很大，托管速度快，更新游戏迅速。 

- 在 ROM 板块推荐 [LoLROMs](https://fmhy.net/gaming#rom-sites)，合集较新，覆盖热门与冷门主机，收录数千款游戏，并支持一键下载。

- 在游戏模组中推荐 [Thunderstore](https://fmhy.net/gaming-tools#game-mods)，模组 + 模组管理器，主要面向 Unity 游戏（也有其他），库很大，有些人更喜欢它而不是 Nexus。 

- 在书籍推荐中推荐 [StoryGraph](https://fmhy.net/reading#book-tracking-databases)，书籍追踪 / 推荐网站，功能非常丰富，有些人更喜欢它而非 GoodReads。

- 在漫画推荐中推荐 [Comic Book Reading Orders](https://fmhy.net/reading#comic-recommendations)，阅读顺序目录非常庞大，最早可追溯到 60 年代。 

- 推荐 [The Book Prize Index](https://fmhy.net/reading#book-recommendations)，不错的图书奖项 + 获奖书籍索引。

- 在优化工具中推荐 [OptiScaler](https://fmhy.net/gaming-tools#optimization-tools)，Windows 游戏超分工具，利用游戏运动矢量获得更好效果，不像 Lossless Scaling 那样出现画面扭曲。

- 在电影/电视下载中推荐 [MKV BASE](https://fmhy.net/video#download-sites)，库非常大，托管服务器也很好。

- 在动漫流媒体中推荐 [Yeanime](https://fmhy.net/video#anime-streaming)，界面美观，播放速度快，似乎颇受欢迎。

- 在重定向绕过中推荐 [Bypass (lc)](https://fmhy.net/internet-tools#redirect-bypass)，效果不错，支持许多网站。

- 在隐私搜索引擎中推荐 [Startpage](https://fmhy.net/privacy#search-engines)，本质上是隐私保护更好的 Google 前端，某些情况下搜索结果比其他隐私搜索引擎更好。

# 已移除内容 {#things-removed}

- 移除了 Cromite，因为它现在已落后 3 个 Chromium 大版本，存在许多问题，而且开发者表示要休息一段时间；如果它将来回归，我们会重新加入。

- 已将 Nightcord 加入我们的不安全列表，他们过去似乎曾被发现[记录 Discord 令牌](https://i.ibb.co/gbG0SYhM/image.png)。请注意，我们并未在 FMHY 上列出过它，只是想帮忙把这一信息传播出去。
