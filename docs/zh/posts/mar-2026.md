# 新增推荐 ⭐ {#stars-added-⭐}

- 在文档分区推荐了 [Epstein Exposed + JMail](https://fmhy.net/reading#declassified-leaked-documents) 这两个，我们收到过很多此类项目，但这两个的 UI 似乎更好。

- 在文件转换器中推荐了 [Convert to it!](https://fmhy.net/file-tools#file-converters)，几乎涵盖所有能想到的格式，文件上传仅在浏览器内完成，不会上传给他们，这对隐私很有好处。

- 在未封锁浏览器游戏中推荐了 [GN-Math](https://fmhy.net/gaming#unblocked-games)，有许多优秀的移植作品，似乎很受欢迎。

- 在字体工具中推荐了 [Font Analyzer](https://fmhy.net/text-tools#font-tools)，可分析任意页面的字体并给出相似的替代字体。

- 在 Pastebins 中推荐了 [Markbox](https://fmhy.net/text-tools#pastebins)（又名 fluffle），是 rentry 的替代品，UI 相似，支持 Markdown、编辑等功能。

- 在图像编辑中推荐了 [Efecto](https://fmhy.net/image-tools#image-effects)，基于网页的视觉效果编辑器，支持图像、视频和 3D 模型。

- 在视频生成中推荐了 [KLIPY](https://fmhy.net/ai#video-generation)，可使用 Veo 3 无限制生成 GIF。

- 推荐了 [Image-Upscaling](https://fmhy.net/image-tools#upscale-restore)，在线图像放大工具，处理速度快，效果良好。

- 在图像生成中推荐了 [Google Flow](https://fmhy.net/ai#image-generation)，可无限使用 Nano Banana Pro / Nano Banana 2。 

- 在图像生成中推荐了 [Khoj](https://fmhy.net/ai#image-generation)，可无限使用 Nano Banana / Imagen 4。

- 在教育技能中推荐了 [Knots 3D](https://fmhy.net/educational#skills-hobbies-diy)，学习打各种结的 3D 互动指南。 

- 在专用聊天机器人中推荐了 [Google AI Mode](https://fmhy.net/ai#specialized-chatbots)，AI 搜索引擎，可无限使用 Gemini 3。

- 在审查绕过分区推荐了 [Net4People](https://fmhy.net/privacy#anti-censorship)，全球审查规避讨论，交流在 GitHub issue 区进行。 

- 在 VPN 服务器中推荐了 [NetBird](https://fmhy.net/privacy#vpn-server)，类似 Tailscale 的 WireGuard Mesh，但它是开源的、可自托管，并有 Web UI。 

- 在 RSS 阅读器中推荐了两个 [FreshRSS](https://fmhy.net/internet-tools#rss-readers) 实例（rss.fmhy + Prodottoinrete），可自定义、基于网页，并支持无限订阅源。
