# 新增星标 ⭐ {#stars-added-⭐}

- 在文档分区推荐了 [Epstein Exposed + JMail](https://fmhy.net/reading#declassified-leaked-documents)，我们收到过很多这类项目，但这两个的界面似乎更好一些。

- 在文件转换器中推荐了 [Convert to it!](https://fmhy.net/file-tools#file-converters)，几乎支持所有能想到的格式，文件上传仅在浏览器内进行，不会上传到他们的服务器，这对隐私很有利。

- 在免封锁浏览器游戏中加星推荐 [GN-Math](https://fmhy.net/gaming#unblocked-games)，它包含许多优秀的移植版本，似乎很受欢迎。

- 在字体工具中加星推荐 [字体分析器](https://fmhy.net/text-tools#font-tools)，可分析任意页面中的字体并给出相似的替代字体。

- 在 Pastebin 类网站中推荐了 [Markbox](https://fmhy.net/text-tools#pastebins)（又名 fluffle），是 rentry 的替代品，界面相似，支持 Markdown、编辑等功能。

- 在图片编辑中推荐了 [Efecto](https://fmhy.net/image-tools#image-effects)，网页版视觉效果编辑器，支持图片、视频和 3D 模型。

- 在视频生成中推荐了 [KLIPY](https://fmhy.net/ai#video-generation)，可使用 Veo 3 无限生成 GIF。

- 推荐了 [Image-Upscaling](https://fmhy.net/image-tools#upscale-restore)，在线图片超分工具，速度快，效果不错。

- 在图片生成中推荐了 [Google Flow](https://fmhy.net/ai#image-generation)，可无限使用 Nano Banana Pro / Nano Banana 2。 

- 在图片生成中推荐了 [Khoj](https://fmhy.net/ai#image-generation)，可无限使用 Nano Banana / Imagen 4。

- 在教育技能中推荐了 [Knots 3D](https://fmhy.net/educational#skills-hobbies-diy)，3D 互动指南教你打各种绳结。 

- 在专业聊天机器人中推荐了 [Google AI Mode](https://fmhy.net/ai#specialized-chatbots)，AI 搜索引擎，可无限使用 Gemini 3。

- 在审查绕过分区推荐了 [Net4People](https://fmhy.net/privacy#anti-censorship)，全球审查规避讨论，交流在 GitHub issue 区进行。 

- 在 VPN 服务器中推荐了 [NetBird](https://fmhy.net/privacy#vpn-server)，类似 Tailscale 的 WireGuard Mesh，但它是开源的、可自托管，并有网页界面。 

- 在 RSS 阅读器中推荐了两个 [FreshRSS](https://fmhy.net/internet-tools#rss-readers) 实例（rss.fmhy + Prodottoinrete），可定制、网页版，并支持无限订阅源。
