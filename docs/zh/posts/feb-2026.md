# 新增星标 ⭐ {#stars-added-⭐}

- 在游戏启动器中推荐了 [Hydra](https://fmhy.net/gaming-tools#game-launchers)。支持基于插件的下载、BT、RD + TorBox，自定义功能出色，还有成就、好友列表、游戏时长监控、云存档等。⁠

- 在 Android 音频分类中推荐了 [SpotiFLAC-Mobile](https://fmhy.net/mobile#android-audio)。这是一款开源下载应用，支持多个网站。

- 在 MC 启动器中推荐了 [ElyPrismLauncher + Freesm Launcher](https://fmhy.net/gaming-tools#launchers)。两者都是 Prism 功能丰富的分支，比我们试过的其他分支更出众。

- 在 AI聊天机器人中推荐了 [Gemini](https://fmhy.net/ai#official-model-sites)。Gemini 3 Flash 现在表现良好，在 LMArena 上排名靠前。

- 在 Android YouTube + Android YouTube Music 分类中推荐了 [Morphe](https://fmhy.net/mobile#android-youtube-apps)。这是一款无广告 YouTube 补丁工具 / ReVanced 替代品。

- 在视频下载中推荐了 [XDMovies + The One Piece](https://fmhy.net/video#download-sites)。两者都有庞大的资源库 + 高速主机。

- 在 Android 视频播放器中推荐了 [mpvEx](https://fmhy.net/mobile#android-video-players)。功能丰富的 mpv 分支，改进的 UI，维护良好。

- 在游戏下载中推荐了 [Virgil Game Search](https://fmhy.net/gaming#download-games)。自定义的多网站游戏下载搜索引擎；仅使用可信来源。

- 在免费软件网站中推荐了 [Dan Store](https://fmhy.net/downloading#freeware-sites)。网页版 Microsoft Store 浏览器；无需 Microsoft Store 应用即可使用。

- 在电子书阅读器中推荐了 [KoReader](https://fmhy.net/reading#ebook-readers)。开源、高度可自定义、支持插件；非常适合电子书阅读器。

- 在电影推荐工具中推荐了 [Nothing To Watch](https://fmhy.net/video#recommendation-tools)。互动式发现可视化；一种有趣/独特的找片方式。

- 在地理中推荐了 [Ekvis](https://fmhy.net/educational#geography-sociology)。维护良好且实用的地理学习网站；涵盖 220+ 国家、旗帜、地区等。

- 在浏览器游戏中推荐了 [Slope Plus](https://fmhy.net/gaming#browser-games)。Slope 的更新版本；有额外功能、游戏模式，以及活跃的自定义地图社区。

- 在图片 + 视频生成中推荐了 [GeminiGen AI](https://fmhy.net/ai#video-generation)。提供无限 Nano Banana Pro 图片，以及无限 Sora 2、Veo 3.1 和 Grok 视频。

- 在图片生成中推荐了 [Perchance](https://fmhy.net/ai#image-generation)。无限、免注册，且质量方面提升了很多。

- 在 Lo-Fi 电台中推荐了 [Flow-Fi](https://fmhy.net/audio#lofi-radio)。有大量电台和视频背景选项；质量比我们收到的大多数 lo-fi 网站更高。

- 在导航部分推荐了 [StreetComplete](https://fmhy.net/misc#navigation-transport)。通过完成任务帮助补全缺失的 OpenStreetMap 数据。

- 在浏览器游戏中推荐了 [Flash Arch、Kongregate 和 Crazy Games](https://fmhy.net/gaming#multi-game-sites)。看完这一部分后，这三个似乎最突出，但如果我们漏掉了其他好网站，欢迎告诉我们。我们也考虑过 AddictingGames + Poki，但对两者都不太有把握。
