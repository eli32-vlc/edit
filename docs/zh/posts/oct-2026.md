# Wiki 更新 {#wiki-updates}

- 根据 **[polls](https://challonge.com/ajqvt0wo/fullscreen)** 及期间进行的讨论重新排序了 [Live Sports](https://fmhy.net/video#live-sports)。感谢所有投票的人，并祝贺所有排名上升或保持高位的网站。

- 清理了 [Interesting Section](https://fmhy.net/misc#interesting)，移除了所有失效或无意义的网站，并将其中部分内容拆分到 Fun 下的 2 个新子分区：[Media / Lore](https://fmhy.net/misc#media-lore) + [Mysteries / Paranormal](https://fmhy.net/misc#mysteries-paranormal)。感谢 @jochen 的想法。

- 在 Gaming Tools 中添加了 [Settings / Fixes](https://fmhy.net/gaming-tools#settings-fixes) 部分。

- 在 Shopping 中添加了 [Books / Audiobooks](https://fmhy.net/misc#books-audiobooks) 部分。感谢 @I. Faust 的想法。

- 添加了 [Stream Lounges](https://fmhy.net/video#stream-lounges) 部分，这类网站会播放或允许用户播放随机的电影或节目，通常还带有聊天室。

- 添加了 [Desktop Streaming Apps](https://fmhy.net/video#streaming-apps) + [Anime Streaming Apps](https://fmhy.net/video#anime-streaming-apps) 部分。

- 在 Video Download 部分下添加了 [Specialty Download](https://fmhy.net/video#specialty-downloading) 部分。

- 将 [Survival / Preparedness](https://fmhy.net/educational#survival-preparedness) 部分从 Storage 移到 Edu > Skills，并重新排序、添加了描述。

- 按流派流行度重新组织了 [Genre Specific Ripping](https://fmhy.net/audio#genre-specific-ripping)（Hip Hop -> Electronic -> Rock/Metal/Punk -> Pop/K-Pop/Disco -> Classical -> Jazz/Fusion -> Bluegrass -> World -> Niche/Experimental）。FLAC 网站位于 MP3 之上。感谢 @Myuui 完成此工作。

- 重新组织了 [Game Soundtrack](https://i.ibb.co/355Rg75x/image.png) / [2](https://i.imgur.com/dbrqrUK.png) 部分，修复了链接，将适合放在一起的网站移到同一行。感谢 @Myuui 完成此工作。

- 重新组织了 [Audio Tracking / Databases](https://fmhy.net/audio#tracking-databases)，将适合放在一起的网站合并到同一行，并尽量使其 [更易于导航](https://i.ibb.co/n83RPsGp/image.png) / [2](https://i.imgur.com/ysUDaxy.png)。感谢 @Myuui 完成此工作。

- 添加了 Simkl/Trakt/MAL/Anilist 等集成作为 #5 中 [stream grading](https://github.com/fmhy/FMHY/wiki/Stream-Site-Grading) 的可选评分方式。网站不会因为缺少此功能而受到惩罚，这只是现在在此评分的 3 种方式（登录/代码/第三方）之一。

- 将 [Global Crisis Support Resources](https://fmhy.net/misc#assistance-charity) 作为索引添加到 Misc > Assistance 部分。

# 新增推荐 ⭐ {#stars-added-⭐}

- 在 FOSS APKs 中推荐了 [F-Droid](https://fmhy.net/mobile#foss-apks)，这是最受喜爱和信任的开源应用来源之一。请注意，Droid-ify（f-droid 前端）在同一部分被推荐，这就是为什么 F-Droid 本身直到现在才被推荐。

- 在 Audio Streaming Apps 中推荐了 [Limusic](https://fmhy.net/audio#streaming-apps)，它似乎是目前最干净、最快、[功能最丰富](https://i.ibb.co/nq0JpBtQ/image.png) / [2](https://i.imgur.com/K7n7ddI.png) 的 YouTube Music 开源桌面客户端。

- 在 Video Downloaders 中推荐了 [lostnode](https://fmhy.net/video-tools#video-download)，支持 600+ 来源，拥有漂亮的 UI + 快速下载。

- 在 Game Download 中推荐了 [Kryoto](https://fmhy.net/gaming#download-games)，资源库庞大、服务器速度快、UI 独特，短时间内便广受好评。

- 在 Audio Ripping 中推荐了 [Antra Web](https://fmhy.net/audio#audio-ripping-sites)，运行良好，支持多种格式和网站。

- 在 System Audio 中推荐了 [VoiceMeeter](https://fmhy.net/system-tools#system-audio)，制作精良的虚拟音频混音器，带有 Voicemeeter Banana + 通用路由，适用于硬件输入输出以及软件。

- 在 YouTube Music Tools 中推荐了 [Better Lyrics](https://fmhy.net/audio#youtube-music-tools)，主题漂亮、同步准确，在建议帖中深受用户喜爱。

- 在 iOS 广告拦截中推荐 [wBlock](https://fmhy.net/mobile#ios-adblocking)，快速、功能丰富的 Safari 广告拦截器，支持自定义屏蔽列表、用户脚本/用户样式引擎等。

- 在图书推荐中推荐 [LibraryThing Awards](https://fmhy.net/reading#book-recommendations)，优秀的图书奖项与获奖图书索引，汇总主要奖项、年度榜单及[更多内容](https://i.ibb.co/SXKJ3fJc/image.png) / [2](https://i.imgur.com/ZIc5Rfb.png)。

- 在复古浏览器模拟器中推荐 [Retro Online](https://fmhy.net/gaming#retro-browser-emulators)，拥有 800 多款游戏，试用过的人给予了相当多的正面评价。

- 在视频工具中推荐 [Autocompressor](https://fmhy.net/video-tools#online-processing)，提供免费档位，文件大小上限 2 GB，上传下载快速，超时极少。

- 推荐 [Spoti.pw](https://fmhy.net/mobile#ios-audio)，它似乎是目前 iOS 上无广告 Spotify 的最佳选择。

- 在 Linux 应用中推荐 [Vicinae](https://fmhy.net/linux-macos#linux-apps)，开源应用启动器，设置简单，兼容 raycast/脚本等。

- 在文件托管中推荐 [Mocha](https://fmhy.net/file-tools#file-hosts)，单文件 15GB，存储 100GB，最后一次下载后保留文件 30 天。

- 在文件托管中推荐 [DropDrive](https://fmhy.net/file-tools#file-hosts)，单文件 100GB，最后一次下载后保留文件 30 天。

- 在心理健康板块推荐 [/mental health/](https://fmhy.net/misc#mental-health)，研究充分、编排得当，不少人表示对自己有帮助。

- 在 macOS 系统工具中推荐 [Vorssaint](https://fmhy.net/linux-macos#system-tools)，开源菜单栏工具包，功能 / 实用工具众多，包括音量混合器、键盘快捷键、屏幕录制等。

- 在国际象棋学习中推荐 [Pawn Appétit](https://fmhy.net/educational#chess)，是我们此前推荐的 En Crossiant 的更新且[功能丰富](https://i.ibb.co/v4pkQJsQ/image.png) / [2](https://i.imgur.com/2ozAnyF.png)的分支。

- 在国际象棋学习中推荐 [OpeningTree](https://fmhy.net/educational#chess)，可从 Chess.com 或 Lichess 拉取棋手对局历史，并将对局映射到[交互式棋盘](https://i.ibb.co/LDSnHmx3/image.png) / [2](https://i.imgur.com/8Sl7d06.png)。

- 在国际象棋板块推荐 [PyChess](https://fmhy.net/gaming#chess)，采用 Lichess 架构并[扩展](https://i.ibb.co/MD1bTHJq/image.png) / [2](https://i.imgur.com/T2CGAph.png)为一个庞大、免费、开源的博物馆和竞技场，涵盖 60 多种地区性、历史性和童话国际象棋变体。

- 在 Linux 游戏中推荐 [Accela](https://fmhy.net/linux-macos#linux-gaming)，Steam 游戏 + DLC 解锁器，界面美观，开发团队优秀，对用户来说似乎运行良好。

- 在 IPTV 播放器中推荐 [ynoTV](https://fmhy.net/video#iptv-players)，界面美观，功能丰富，比分/比赛查找，自定义播放列表，trakt/simkl 集成等。
