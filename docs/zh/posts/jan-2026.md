# 新增推荐 ⭐ {#stars-added-⭐}

- 在视频下载中推荐 [DDLBase](https://fmhy.net/video#download-sites)。既有 4K + 1080p 内容，仅使用高速主机，且资源库庞大。

- 在动漫在线观看板块推荐 [Anime Realms](https://fmhy.net/video#anime-streaming)。片源良好、UI 美观、自动播放下一集、自定义播放器，并支持多语言。

- 在 Telegram 音频机器人板块推荐 [Music Hunters](https://fmhy.net/audio#telegram-bots)。支持大量站点、音质良好且易于使用。

- 在游戏下载中推荐 [AstralGames](https://fmhy.net/gaming#download-games)。资源库庞大、主机速度快、提供预装，并接受请求。

- 在漫画站点中推荐 [Comix](https://fmhy.net/reading#manga)。漫画库庞大、允许上传、UI 美观，并将很快添加更多语言。

- 在音频在线观看板块推荐 [Monochrome](https://fmhy.net/audio#streaming-sites)。无需注册、多 API 集成、Last.fm 集成、可自定义，且曲库庞大。

- 推荐在线观看板块中的 [Rive、Aether、Willow 和 FlyX](https://fmhy.net/video)。它们拥有美观的自定义播放器、功能丰富、流媒体速度快，且 UI 令人印象深刻。

- 在体育直播中推荐 [StreamSports99](https://fmhy.net/video#live-sports)。服务器速度快，UI 可靠。

- 在 Twitter/X 定制中推荐 [Control Panel for Twitter](https://fmhy.net/social-media-tools#twitter-x-customization)。添加了许多额外功能，可隐藏你不使用的板块、改善 UI，还有更多。

- 在文件托管中推荐 [Rootz](https://fmhy.net/file-tools#file-hosts)。速度良好、单文件 25GB，且最后一次下载后保留 15 天。 

- 在图像生成中推荐 [PigenAI](https://fmhy.net/ai#image-generation)。可无限使用 Imagen 4、Qwen 和 Nano Banana。

- 在 iOS 在线观看分类中推荐 [Nuvio](https://fmhy.net/mobile#ios-streaming)。它使用 Stremio 插件，且限制比目前在 iOS 上可用的“Lite”版本更少。

- 在 Android BT 下载分类中推荐 [Flud](https://fmhy.net/mobile#android-torrenting)。它支持绑定，维护良好，且广告可通过 DNS 轻松屏蔽。

- 在身体健康分类中推荐 [Sleeping Guide](https://fmhy.net/misc#physical-health)。这是一份睡眠卫生／科学指南，目前似乎广受好评，由 Dan 整理。

- 在重制版 / 复刻版分类中推荐 [OpenMW](https://fmhy.net/gaming#remakes-recreations)。这是从零开始完整重新实现 Morrowind，[已获 Bethesda 自己认可](https://wiki.openmw.org/index.php?title=Bethesda_Emails)。

- 在重制版 / 复刻版分类中推荐 [Clone Hero](https://fmhy.net/gaming#remakes-recreations)。功能丰富的 Guitar Hero 复刻版，包含上千首歌曲和播放列表，无延迟，兼容所有吉他控制器，并支持 MIDI 鼓组。

- 在多人在线浏览器游戏分类中推荐 [Gidd](https://fmhy.net/gaming#party-multiplayer)。它提供了 Monopoly、GeoGuessr、卡牌游戏等的高质量版本。 

- 在虚拟机分类中推荐 [QEMU](https://fmhy.net/system-tools#virtual-machines)。它在非 Windows 系统上表现良好；最好搭配 Virt-Manager 或 Vagrantup 使用。

- 在文件备份分类中推荐 [Restic](https://fmhy.net/file-tools#file-backup)。它易于使用、支持多平台，并且在基准测试中表现良好。

- 在编程 AI 分类中推荐 [Gemini CLI](https://fmhy.net/ai#coding-ais)。就目前而言，它的额度似乎属于最好的那一档。

# 已移除内容 {#things-removed}

- 移除 CrocDB，因为它已[受到 DMCA 打击](https://i.ibb.co/RpDvJFgf/image.png) / [2](https://i.imgur.com/iSV0MHq.png)。 

- 移除 IcebergCharts 网站，因为它[如今已被黑客入侵过好几次](https://i.ibb.co/XxMMwqDk/image.png) / [2](https://i.imgur.com/MkvElvr.png)，且他们搞不清原因。如果他们弄清楚原因，我们可能会在未来重新添加。请注意，我们暂时会在原位置保留其 subreddit。

- 移除 CanvasBlocker，因为它仅支持 Firefox，而 FF 现已内置该功能；此外它显然在某些情况下可能让指纹识别更糟，且维护状况已大不如前。

- 从体育直播分类中移除 FTV 和 WAC，因为二者现已停运。

- 移除 Foxified，因为它突然[在结果中塞满广告](https://i.ibb.co/4RzPsQ8Z/image.png) / [2](https://i.imgur.com/AjBMdfX.png)。 

- 取消推荐 OnTheSpot，因为它即将失去 Spotify 支持。

- 在编程 AI 分类中取消推荐 Windsurf，因为其额度和免费模型已不如从前。
