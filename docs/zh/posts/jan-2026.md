# 新增星标 ⭐ {#stars-added-⭐}

- 推荐视频下载中的 [DDLBase](https://fmhy.net/video#download-sites)。同时提供 4K + 1080p 内容，仅使用高速主机，且资源库非常庞大。

- 推荐动漫流媒体中的 [Anime Realms](https://fmhy.net/video#anime-streaming)。资源好，界面美观，自动播放下一集，自定义播放器，并支持多语言。

- 在 Telegram 音频机器人中推荐了 [Music Hunters](https://fmhy.net/audio#telegram-bots)。支持大量网站，音质好，且易于使用。

- 推荐游戏下载中的 [AstralGames](https://fmhy.net/gaming#download-games)。资源库庞大，主机速度快，提供预装版本，并接受请求。

- 推荐日漫网站中的 [Comix](https://fmhy.net/reading#manga)。库庞大，允许上传，界面美观，并将很快添加更多语言。

- 推荐音频流媒体中的 [Monochrome](https://fmhy.net/audio#streaming-sites)。免注册，多 API 集成，Last.fm 集成，可自定义，且库庞大。

- 推荐流媒体中的 [Rive、Aether、Willow 和 FlyX](https://fmhy.net/video)。这些站点拥有精美的自定义播放器、丰富功能、快速的流媒体加载和令人印象深刻的界面。

- 推荐体育直播中的 [StreamSports99](https://fmhy.net/video#live-sports)。服务器速度快，界面可靠。

- 推荐 Twitter/X 自定义中的 [Control Panel for Twitter](https://fmhy.net/social-media-tools#twitter-x-customization)。添加了大量额外功能，可隐藏你不使用的部分，改进界面，等等。

- 推荐文件托管中的 [Rootz](https://fmhy.net/file-tools#file-hosts)。速度快，每个文件 25GB，最后一次下载后保留 15 天。 

- 推荐图像生成中的 [PigenAI](https://fmhy.net/ai#image-generation)。可无限使用 Imagen 4、Qwen 和 Nano Banana。

- 在 iOS 流媒体中推荐 [Nuvio](https://fmhy.net/mobile#ios-streaming)。它使用 Stremio 插件，限制比目前 iOS 上可用的 "Lite" 版本更少。

- 在 Android BT 下载中推荐 [Flud](https://fmhy.net/mobile#android-torrenting)。支持绑定，维护良好，且广告可通过 DNS 轻松屏蔽。

- 在身体健康中推荐 [睡眠指南](https://fmhy.net/misc#physical-health)。一份睡眠卫生/科学指南，目前似乎反响不错，由 Dan 整理。

- 在重制 / 复刻中推荐 [OpenMW](https://fmhy.net/gaming#remakes-recreations)。它从零开始完整重新实现了 Morrowind，[并已获得 Bethesda 官方认可](https://wiki.openmw.org/index.php?title=Bethesda_Emails)。

- 在重制 / 复刻中推荐 [Clone Hero](https://fmhy.net/gaming#remakes-recreations)。功能丰富的 Guitar Hero 克隆，数千首歌曲 + 播放列表，无延迟，兼容所有吉他控制器，并支持 MIDI 鼓组。

- 在多人浏览器游戏中推荐 [Gidd](https://fmhy.net/gaming#party-multiplayer)。提供 Monopoly、GeoGuessr、卡牌游戏等的高质量版本。 

- 在虚拟机中推荐了 [QEMU](https://fmhy.net/system-tools#virtual-machines)。在非 Windows 系统上性能良好；最好与 Virt-Manager 或 Vagrantup 配合使用。

- 在文件备份中推荐 [Restic](https://fmhy.net/file-tools#file-backup)。易于使用、多平台，在基准测试中表现出色。

- 在编程 AI 中推荐 [Gemini CLI](https://fmhy.net/ai#coding-ais)。目前它的额度限制似乎是最优的之一。

# 已移除内容 {#things-removed}

- 移除 CrocDB，因其[遭到 DMCA](https://i.ibb.co/RpDvJFgf/image.png) / [2](https://i.imgur.com/iSV0MHq.png)。 

- 移除 IcebergCharts 网站，因其[已被黑客攻击数次](https://i.ibb.co/XxMMwqDk/image.png) / [2](https://i.imgur.com/MkvElvr.png)，且至今无法查明原因。如果他们查明原因，我们可能会在未来重新添加。注意，我们暂时会在原位置保留其子版块。

- 移除 CanvasBlocker，因其仅支持 Firefox，而 FF 现已内置此功能；此外，它在某些情况下显然还会让指纹识别更容易，且维护状况已大不如前。

- 从体育直播中移除 FTV 和 WAC，两者现已关闭。

- 移除 Foxified，因其突然[在搜索结果中塞满广告](https://i.ibb.co/4RzPsQ8Z/image.png) / [2](https://i.imgur.com/AjBMdfX.png)。 

- 将 OnTheSpot 设为未推荐，因为它很快将不再支持 Spotify。

- 将编码 AI 中的 Windsurf 设为未推荐，因为它的限制和免费模型已不如从前。
