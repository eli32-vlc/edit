# Wiki 更新 {#wiki-updates}

- 新增了一个 **[Guide](https://fmhy.net/other/selfhosting)**，用于在本地搭建并运行你自己的 FMHY 实例。

- 新增了 FMHY Safeguard 的 **[Userscript](https://greasyfork.org/en/scripts/528660-fmhy-safelink-guard)** 版本。

- 现在可以使用侧边栏中的图标为网站选择[自定义文字颜色](https://i.imgur.com/kXNRPjM.mp4)，并更新了反馈系统使其更加醒目。

- 清理了电视剧在线观看板块，移除了失效 / 不良站点，并推荐了几个似乎效果最好的站点，[修改前后对比](https://i.imgur.com/E3QTrUn.png)。

- 清理了日语学习板块，请注意没有移除任何站点，只是移动了位置，[修改前 vs 修改后](https://i.imgur.com/wPboWjk.png)。

- 为[AI 视频生成器](https://fmhy.net/ai#video-generation)添加了使用限制标签。

- 更好地整理了字体板块，并拆分为[生成器](https://fmhy.net/text-tools#font-text-generators)和[自定义](https://fmhy.net/text-tools#font-customization)。

- 为我们的在线观看站点评分系统添加了几条[新标准](https://i.imgur.com/s7UGdIz.png)。

# 新增推荐 ⭐ {#stars-added-⭐}

- 在 Audio DDL 中推荐了 [DAB Music Player](https://fmhy.net/audio#download-sites)。单击即可下载 FLAC 专辑，提供 Web 应用 + Windows、Mac 和 Linux 桌面应用，即将支持 Android。

- 在 Android 隐私浏览器中推荐了 [IronFox](https://fmhy.net/storage#privacy-based)。基于 Firefox 的浏览器，专注于隐私 / 安全。功能丰富，受到 LibreWolf 开发团队推荐，我们的社区似乎也很喜欢它。

- 在 Twitch 广告拦截器中推荐了 [AdGuardExtra](https://fmhy.net/social-media-tools#twitch-adblockers)。这似乎是目前拦截它们的最佳方式。

- 在 YouTube 视频下载器中推荐了 [AMP4](https://fmhy.net/social-media-tools#youtube-downloaders)，无广告，支持播放列表和 3 小时长的视频。

- 在网络隐私中推荐了 [JustDeleteMe](https://fmhy.net/privacy#web-privacy)。一个链接目录，可更轻松地从网络服务中删除你的账户。

- 在播客在线观看中推荐了 [PocketCasts](https://fmhy.net/audio)。受欢迎的 iOS 播客播放器，最近新增了桌面 + Web 应用。

- 在航班板块中推荐了 [ADS-B Exchange](https://fmhy.net/misc#flights)，是少数不把功能锁在付费墙后的站点之一。

- 在无广告 Spotify 中，将 xManager 的推荐替换为 [ReVanced Manager](https://fmhy.net/mobile#android-audio)，因为它功能更多、问题更少，且 xManager 本身也推荐它。

- 移除了 Bark 的推荐（因为它有限制），以及 Tortoise TTS 的推荐（因为听起来效果不好），改为推荐 [TTS Online](https://fmhy.net/ai#text-to-speech)，它听起来更好，且每日字符限制为 10k。

# 已移除内容 {#things-removed}

- 移除了 TorrentGalaxy，遗憾的是它看起来短期内不会恢复。

- 从 Audio DDL 中移除了 The Last Disaster，因为它们已关停。

- 从电视直播中移除了 TOTV，因为现在每个频道似乎都是 YouTube 视频。

- 取消了 Plex 的推荐，因为他们将远程在线观看改为[仅付费](https://www.plex.tv/blog/important-2025-plex-updates/)，并同时提高了价格。

- 取消了 PSArips 的推荐，因为它们的下载流程非常烦人。

- 取消了 Bookracy 的推荐，因为它最近一段时间一直有问题。
