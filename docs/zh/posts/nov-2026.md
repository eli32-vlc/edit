# 新增推荐 ⭐ {#stars-added-⭐}

- 在 iOS iPAs 中推荐了[ShrubLibrary](https://fmhy.net/mobile#ios-ipas)，应用众多，支持自定义源，UI 简洁。

- 在电子阅读器工具中推荐了[calibre](https://fmhy.net/reading#e-reader-tools)，可定制的电子书管理应用，带有转换器、编辑器、阅读器等。

- 在音乐追踪 / 数据库中推荐了[Discogs](https://fmhy.net/audio#tracking-databases)，最大、维护最好且广受认可的音乐数据库之一。

- 在漫画中推荐了[Toonkotsu](https://fmhy.net/reading#manga)，UI 和阅读器都不错，支持多源，似乎很受欢迎。

- 在趣味板块中推荐了[The Pudding](https://fmhy.net/misc#interesting)，高质量的交互式数据可视化和视觉文章。 

- 在 Pastebins 中推荐了[Paster](https://fmhy.net/text-tools#pastebins)，支持多语法、Markdown 和编辑代码。

- 在绘画 / 绘图部分推荐了[Inkscape](https://fmhy.net/image-tools#painting-drawing)，开源矢量图形编辑器，被许多人认为是 Illustrator 的良好免费替代品。

- 在动漫在线观看中推荐了 [Ani(pm) + NekoWatch](https://fmhy.net/video#anime-streaming)，两者速度都很快，UI / 功能也不错，似乎很受欢迎。

- 在在线观看分类中推荐了 [Fly Stream, dulo, Spacedom & CineLite](https://fmhy.net/video#stream-aggregators)，它们有自定义播放器、不错的 UI 和稳定的服务器。

- 在图片素材部分推荐了 [Unsplash](https://fmhy.net/image-tools#stock-images)，图库庞大、图片质量高，无需注册。

- 在 Roblox 工具中推荐了 [Fishstrap](https://fmhy.net/gaming-tools#roblox-tools)，因为它类似 Bloxstrap，但似乎维护得更好。

- 在演唱会 / 现场演出中推荐了 [Tiny Desk Concerts](https://fmhy.net/audio#concerts-live-shows)，NPR 于 2008 年推出的热门的近距离现场演出系列，已有 1000+ 场演出。

- 在演唱会 / 现场演出中推荐了 [MixesDB](https://fmhy.net/audio#dj-mixes-livesets)，一个庞大且维护良好的 DJ 演出、电台节目和混音数据库。

- 在 Movie Rec Tools 中推荐 [Sight and Sound](https://fmhy.net/video#recommendation-tools)，该投票自 1952 年起[每十年](https://en.wikipedia.org/wiki/Sight_and_Sound)举行一次，由 1,600+ 影评人、档案管理员等投票。

- 在剧集在线观看中推荐了 [KatDrama](https://fmhy.net/video#drama-streaming)，播放器不错、库大且源多。

- 在身体健康分类中推荐了 [The Fitness Wiki](https://fmhy.net/misc#physical-health)，由 r/Fitness 社区运营的全面且维护良好的 Wiki。

- 在饮品部分推荐了 [Timer.Coffee](https://fmhy.net/misc#drinks)，一款咖啡冲泡应用，带引导式计时器、配方、计算器和[更多](https://i.ibb.co/d0zdgkjw/image.png) / [2](https://i.imgur.com/B61pcPe.png)。

- 在课程在线观看中推荐了 [Gresham College](https://fmhy.net/educational#streaming)，汇集了大量高质量讲座，涵盖许多主题。

- 在离线图片画廊中推荐了 [Immich](https://fmhy.net/image-tools#offline-galleries)，受欢迎、运行良好，由 FUTO 支持。

- 在编码工具中推荐了 [Pi](https://fmhy.net/developer-tools#coding-harnesses-extensions)，热门终端编码代理，可通过扩展、技能、提示和主题自定义。
