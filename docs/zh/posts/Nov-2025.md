# Wiki 更新 {#wiki-updates}

- 已把 **[AMOLED Theme](https://i.ibb.co/hx97zL3W/978676.jpg)** / [2](https://i.imgur.com/fMrnGmF.png) 作为 [切换开关](https://i.ibb.co/pvkfg3hC/image.png) / [2](https://i.imgur.com/qF7exKw.png) 添加到我们的网站，可开启或关闭。感谢 @Land 完成此项工作。

- 构建了一个 **[External Search Engine](https://fmhy-search.dev.zenir.tech/)**，在大多数情况下比我们网站上内置的 VitePress 搜索更好用。

- 新增了一个 FMHY 的 **[New Backup](https://fmhyclone.pages.dev/)**，每日同步，托管在 GitLab。它还包含 [原始 markdown](https://fmhyapi.wispy.qzz.io/single-page) 页面的备份。我们还添加了我们网站的另一个[备份](https://a-fmhy.pages.dev/)，该备份默认启用上述主题。

- 太空部分变得有点难以浏览（60+ 行），所以我们把它拆成了[独立的一级章节](https://fmhy.net/educational#space)，并新增两个子章节：[天文](https://fmhy.net/educational#astronomy) 和 [航天器](https://fmhy.net/educational#spacecraft)。天文涵盖宇宙中的天体或现象。航天器涵盖火箭、发射和 ISS。该一级章节仍用于一般太空相关内容，如 NASA 网站、新闻等。

- 游戏中的重制 / 移植部分有 80 多行且杂乱无章，所以我们将其拆成三个新章节以便更易理解：[反编译 / 移植](https://fmhy.net/gaming#decomps-ports)、[重制 / 复刻](https://fmhy.net/gaming#remakes-recreations) 和 [复活项目](https://fmhy.net/gaming#revival-projects)。我们还将“特殊兴趣”独立为一级分类，以更好地组织目录。

- 根据我们 Discord 的投票结果，重新排序了 [日漫网站](https://fmhy.net/reading#manga)。Weeb Central 升至第 1 位，MangaFire 和 MangaNato 均被设为推荐。感谢所有参与投票的人。[前后对比](https://i.ibb.co/j9Sn4hRR/image.png) / [2](https://i.imgur.com/u8zFZTX.png)。

- 清理了多个音频流媒体章节，并新增了一些章节以优化分类，包括：[特色](https://fmhy.net/audio#specialty-streaming)、[特定流派](https://fmhy.net/audio#genre-specific-streaming)、[电台目录](https://fmhy.net/audio#radio-directories) 和 [Lofi 电台](https://fmhy.net/audio#lofi-radio)。[前后对比](https://github.com/fmhy/edit/pull/4128#issuecomment-3476036920)。感谢 @AnarchyDR 完成此项工作。

- 更新了 [音频流媒体](https://fmhy.net/audio) 目录，使其更简洁、更易于浏览。[前后对比](https://i.ibb.co/0yJbh03H/234243.jpg) / [2](https://i.imgur.com/fhgqKzb.png)。

- 清理了 [浏览器模拟器](https://fmhy.net/gaming#browser-emulators)，修正了标签，移除了失效网站，并将仅作为 EmulatorJS / NeptunJS 前端的网站移至存档。[前后对比](https://i.ibb.co/LXdhcDFD/Untitled.png) / [2](https://i.imgur.com/W9x8jY4.png)。

- 我们移除了 Proton VPN 的“禁止 BT 下载”标签，因为现在可以通过配置 OpenVPN 来免费进行 BT 下载。注意这些配置会过期，需要定期重新生成。指南列在 [Proton](https://fmhy.net/privacy#vpn) 旁边。感谢 Wispy 等人弄清楚了这一点。

- 在游戏中新增了 [俄罗斯方块](https://fmhy.net/gaming#tetris) 章节。

- 修复了游戏优化中混乱的格式。[前后对比](https://i.ibb.co/Vc99kJhh/image.png) / [2](https://i.imgur.com/HRPUwL3.png)。

# 新增星标 ⭐ {#stars-added-⭐}

- 在下载管理器中推荐 [AB Download Manager](https://fmhy.net/file-tools#download-managers)。开源、快速、跨平台，支持断点续传下载，且有活跃的开发团队。 

- 将 [CrocDB](https://fmhy.net/gaming#rom-sites) 提升为 ROM 网站中超越 Myrient 的新第 1 位。Croc 覆盖多个网站，界面更好，并新增了 "rompack" 功能。

- 在 BT 边下边播应用中推荐 [PlayTorrio](https://fmhy.net/video#torrent-apps)。功能丰富的新客户端，支持类似 Stremio 的插件（如 Torrentio）、Jackett 集成和 Debrid 支持。

- 在专用聊天机器人中推荐 [NotebookLM](https://fmhy.net/ai#specialized-chatbots)。非常适合基于文档的聊天和笔记，能很好地处理音频/视频概览，并可生成测验和记忆卡片。

- 在动漫流媒体中推荐 [Anidap](https://fmhy.net/video#anime-streaming)。界面美观，并使用独特的高速源。

- 在电视直播 / 体育中推荐 [PlayTorrio IPTV](https://fmhy.net/video#live-tv)。流媒体速度快、库庞大、质量稳定。请注意 Darkness TV 才是原版；PlayTorrio 改进了界面。

- 在 Linux 游戏中推荐 [Heroic Games Launcher](https://fmhy.net/linux-macos#linux-gaming)。用于 Epic、GOG 和 Prime 游戏的优秀启动器；目前维护状况比 Lutris 更好。

- 在阅读推荐中推荐 [ComicBookRoundup](https://fmhy.net/reading#curated-recommendations)。专注于漫画的评测与评分聚合器，类似 Metacritic。

- 在 ROM 网站中推荐 [Ziperto](https://fmhy.net/gaming#rom-sites)。历史悠久，库庞大，源速度快。

- 在体育直播中推荐 [Sportsbite](https://fmhy.net/video#live-sports)。一个聚合器，拥有众多源、整洁的界面，并覆盖大多数重大赛事。
