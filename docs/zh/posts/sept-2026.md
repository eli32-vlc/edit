# Wiki 更新 {#wiki-updates}

- 站内搜索引擎现在新增了 **[Section Filters](https://i.ibb.co/99gXbTyD/image.png)** / [2](https://i.imgur.com/J1csfSu.png)（游戏、音频、阅读等），在某些情况下可以提升结果质量。感谢 anarchydr 完成这项工作。

- 在备份页面新增了 FMHY 的 **[.onion](http://fnp47tywqhwygfkkik3dkgreocdbevjslzs6fw4zbotomcbqeuyahjqd.onion/)** 版本。感谢 @saber 制作。

- 新增了带自动更新的 FMHY **[Bookmark Extension](https://github.com/mian196/fmhy-bookmarks-extension)**。感谢 @Simon Riley 制作。

- FMHY **[Raycast Search Extension](https://www.raycast.com/akshit_mehta/fmhy-search)** 现已可用，感谢其贡献者提出这个想法并为我们完成。

- 新增了 [查询参数](https://i.imgur.com/S67dReX.png) / [2](https://i.ibb.co/yFyybyfX/Untitled.png) 支持（?q=searchquery）。示例：`https://fmhy.net/?q=test`。感谢 @flower 完成。

- 根据 **[Polls](https://challonge.com/woium3fu/fullscreen)** 及投票期间的讨论，重新调整了 [动漫在线观看站点](https://fmhy.net/video#anime-streaming) 的排序，感谢所有参与投票的人，并祝贺所有排名提升或保持高位的站点。[投票前 vs 投票后](https://i.ibb.co/JW4dqsH7/Untitled.png) / [2](https://i.imgur.com/sNqUdG7.png)

- 电子产品购物部分变得过于臃肿，因此我们决定将其拆分为几个新的子版块以便浏览。感谢 @jochen 提出想法。新子版块：[电子产品 / 科技](https://fmhy.net/misc#electronics-tech)、[移动设备 / 手机](https://fmhy.net/misc#mobile-phones)、[相机](https://fmhy.net/misc#cameras)、[PC 硬件 / 装机](https://fmhy.net/misc#pc-hardware-building)、[TV / 显示器](https://fmhy.net/misc#tv-monitors)、[音频设备](https://fmhy.net/misc#audio-equipment)、[键盘 / 鼠标](https://fmhy.net/misc#keyboards-mice)、[游戏设备](https://fmhy.net/misc#gaming-equipment)

- 在 Educational 中新增了 [AI / ML 学习](https://fmhy.net/educational#ai-ml-learning) 版块。

- 在 Edu History 中新增了 [军事 / 冲突历史](https://fmhy.net/educational#military-conflict-history) 版块。感谢 @Yeet 提出想法并收集站点。

- 在 Browser Games 中新增了 [竞速 / 驾驶](https://fmhy.net/gaming#racing-driving) 版块。

- 在 Indexes 下新增了 [随机站点 / 发现](https://fmhy.net/misc#random-sites-discovery) 版块。

- Minecraft Tools 分类已进行了[全面修订](https://i.ibb.co/svg60Qp2/Untitled.png) / [2](https://i.imgur.com/7V6rWeo.png)。其中包括重新整理和精简部分条目，以方便浏览。感谢 @Myuui、@Flower、@Jul Mik、@Yoshi/MTG、@litekin 协助。

- 移除了 Toggle Starred 与 Toggle Indexes 之间的互斥限制，两个开关现在可以[同时启用](https://i.ibb.co/gMHfjG08/image.png) / [2](https://i.imgur.com/sqPgOK3.png)。感谢 Zenith 完成。

# 新增推荐 ⭐ {#stars-added-⭐}

- 在 Game Downloads 中推荐了 [GoG Revived](https://fmhy.net/gaming#download-games)，这是带更新的 gog-games 1:1 存档。

- 在 Indexes 中推荐了 [Dans Guides](https://fmhy.net/misc#indexes)，因为内容写得很好，受到许多人喜爱。

- 在 Video Download Sites 中推荐了 [downloadeverythingfromeverywhere](https://fmhy.net/video#download-sites)，这是一个聚合器，可抓取多个主机，包括一些一键下载站点。

- 在 Mobile Social Media Apps 中推荐了 [raincord](https://fmhy.net/mobile#social-media-apps)，这是适用于 Android 和 iOS 的修改版 Discord 客户端，是 Kettu 的后继者，有插件，开发团队也不错，对目前使用它的人来说似乎运行良好。

- 在 Stream Aggregators 中推荐了 [Movy](https://fmhy.net/video#stream-aggregators)，加载快速、界面质量高，是近几个月推出的较好站点之一。

- 在 Steam Tools 中推荐了 [LuaTools](https://fmhy.net/gaming-tools#steam-epic)，这是一个类似 SteamMidra 的 Steam 多功能工具 + manifest 工具，但更流畅且不会触发 Defender。

- 在 Music Recommendations 中推荐了 [Shfl](https://fmhy.net/audio#curated-recommendations)，来自音乐作者和艺术家的推荐，拥有庞大曲库、指南、主题列表以及[更多内容](https://i.ibb.co/jP4w9jzF/image.png) / [2](https://i.imgur.com/129i3Dk.png)。 

- 在 Book Recommendations 中推荐了 [NPR's Books We Love](https://fmhy.net/reading#book-recommendations)，[汇集了数千条](https://i.imgur.com/px72ucF.png) / [2](https://i.ibb.co/Kxw7L73t/image.png) 由其数百名记者、评论员和员工精心挑选的推荐。

- 在 Android 图片画廊中推荐 [Refra + Right Gallery](https://fmhy.net/mobile#image-galleries)，两者都有非常漂亮的 UI、大量功能，并且受到试用者的喜爱。

- 在 Minecraft 托管工具中推荐 [Crafty Controller](https://fmhy.net/gaming-tools#hosting-tools)，这是一个跨平台服务器控制器，可在浏览器中运行，支持文件上传、整合包导入等功能。

- 在 Linux 游戏中推荐 [SLSsteam](https://fmhy.net/linux-macos#linux-gaming)，这是带 DLC Unlocker 和模拟成就的 Steamclient Mod。

- 在多模型站点中推荐 [Together.ai](https://fmhy.net/ai#multiple-model-sites)，每日额度不错，免费模型扎实，并且支持网页搜索。

- 在互联网电台中推荐 [AccuRadio](https://fmhy.net/audio#internet-radio)，预设主题频道涵盖数百种风格，无限跳过以及[更多](https://i.ibb.co/6JwVfm8Q/image.png) / [2](https://i.imgur.com/ODhkBNk.png)。

- 在音乐发现中推荐 [NTS Radio](https://fmhy.net/audio#music-discovery)，由超过 [600 位常驻主持人](https://i.ibb.co/HDYDQWXB/image.png) / [2](https://i.imgur.com/8ckHCwU.png) 组成的全球社区引领，包括音乐人、DJ、艺术家和唱片收藏家，另有嘉宾节目和特别节目。 

- 在 MOBA 工具中推荐 [Rose](https://fmhy.net/gaming-tools#moba-tools)，LoL 皮肤管理器 / 解锁器，使用安全，没有人报告过任何类型的问题，拥有游戏中的每一款皮肤（仅在你的屏幕上显示）。

- 在 iOS 社交媒体中推荐 [RyukGram](https://fmhy.net/mobile#social-media-apps-1)，一款持续维护的 Instagram 插件，试用者反馈良好，似乎是当前最佳选择。

- 在 iOS 音频中推荐 [8SPINE](https://fmhy.net/mobile#ios-audio)，基于模块的在线观看与下载应用，UI 漂亮，设置丰富，并支持无损播放（配合特定模块）。

- 在语言学习中推荐 [Yomitan](https://fmhy.net/educational#multi-language)，功能丰富的浏览器弹窗词典，支持自定义主题、anki 集成等。

- 在编程基准测试中推荐 [DeepSWE](https://fmhy.net/ai#coding-benchmarks)，非常可靠，频繁更新，并测试模型的所有推理优势。

- 在本地 AI 前端中推荐 [Cherry Studio](https://fmhy.net/ai#local-ai-frontends)，设置简单，UI 漂亮。
