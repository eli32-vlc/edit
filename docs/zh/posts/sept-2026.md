# Wiki 更新 {#wiki-updates}

- 站点搜索引擎现已支持 **[Section Filters](https://i.ibb.co/99gXbTyD/image.png)** / [2](https://i.imgur.com/J1csfSu.png)（游戏、音频、阅读等），在某些情况下可提升搜索结果质量。感谢 anarchydr 完成此项工作。

- 在备份页面添加了 FMHY 的 **[.onion](http://fnp47tywqhwygfkkik3dkgreocdbevjslzs6fw4zbotomcbqeuyahjqd.onion/)** 版本。感谢 @saber 制作。

- 添加了带自动更新的 FMHY **[Bookmark Extension](https://github.com/mian196/fmhy-bookmarks-extension)**。感谢 @Simon Riley 制作。

- FMHY **[Raycast Search Extension](https://www.raycast.com/akshit_mehta/fmhy-search)** 现已可用，感谢其贡献者提出想法并为我们完成开发。

- 添加了 [查询参数](https://i.imgur.com/S67dReX.png) / [2](https://i.ibb.co/yFyybyfX/Untitled.png) 支持（?q=searchquery）。示例：`https://fmhy.net/?q=test`。感谢 @flower 完成此项工作。

- 根据 **[Polls](https://challonge.com/woium3fu/fullscreen)** 及投票期间的讨论，重新调整了 [动漫流媒体站点](https://fmhy.net/video#anime-streaming) 的排序，感谢所有参与投票的人，也祝贺所有排名上升或保持高位的站点。[调整前后对比](https://i.ibb.co/JW4dqsH7/Untitled.png) / [2](https://i.imgur.com/sNqUdG7.png)

- 电子产品购物栏目已变得非常臃肿，因此我们决定将其拆分为若干新的子栏目，以便更易浏览。感谢 @jochen 提出想法。新增子栏目：[电子 / 科技](https://fmhy.net/misc#electronics-tech)、[移动端 / 手机](https://fmhy.net/misc#mobile-phones)、[相机](https://fmhy.net/misc#cameras)、[PC 硬件 / 装机](https://fmhy.net/misc#pc-hardware-building)、[电视 / 显示器](https://fmhy.net/misc#tv-monitors)、[音频设备](https://fmhy.net/misc#audio-equipment)、[键盘 / 鼠标](https://fmhy.net/misc#keyboards-mice)、[游戏设备](https://fmhy.net/misc#gaming-equipment)

- 在教育栏目中添加了 [AI / ML 学习](https://fmhy.net/educational#ai-ml-learning) 分区。

- 在教育历史栏目中添加了 [军事 / 冲突历史](https://fmhy.net/educational#military-conflict-history) 分区。感谢 @Yeet 提出想法并收集站点。

- 在浏览器游戏栏目中添加了 [竞速 / 驾驶](https://fmhy.net/gaming#racing-driving) 分区。

- 在索引栏目下添加了 [随机站点 / 探索发现](https://fmhy.net/misc#random-sites-discovery) 分区。

- Minecraft 工具分类已 [全面修订](https://i.ibb.co/svg60Qp2/Untitled.png) / [2](https://i.imgur.com/7V6rWeo.png)。其中包括重组和精简部分条目，以便更易浏览。感谢 @Myuui、@Flower、@Jul Mik、@Yoshi/MTG、@litekin 协助完成。

- 移除了“切换推荐”与“切换索引”之间的互斥限制，现在两个开关可 [同时](https://i.ibb.co/gMHfjG08/image.png) / [2](https://i.imgur.com/sqPgOK3.png) 启用。感谢 Zenith 完成此项工作。

# 新增星标 ⭐ {#stars-added-⭐}

- 在游戏下载栏目中推荐了 [GoG Revived](https://fmhy.net/gaming#download-games)，它是 gog-games 的 1:1 存档并附带更新。

- 在「索引」中将 [Dans 指南](https://fmhy.net/misc#indexes) 标为推荐，因为其撰写精良，深受众多用户喜爱。

- 在视频下载站点中推荐了 [downloadeverythingfromeverywhere](https://fmhy.net/video#download-sites)，这是一个抓取多个网盘的聚合器，其中包含部分支持一键下载的网盘。

- 在移动端社交媒体应用中推荐了 [raincord](https://fmhy.net/mobile#social-media-apps)，这是适用于 Android 与 iOS 的修改版 Discord 客户端，是 Kettu 的后继者，带有插件，开发团队优秀，对目前使用它的人来说似乎运行良好。

- 在流媒体聚合器中推荐了 [Movy](https://fmhy.net/video#stream-aggregators)，其流媒体加载快速、界面质量高，是近几个月出现的最好的站点之一。

- 在 Steam 工具中推荐了 [LuaTools](https://fmhy.net/gaming-tools#steam-epic)，这是类似 SteamMidra 的 Steam 多工具 + manifest 工具，但更流畅，且不会触发 Defender。

- 在音乐推荐中推荐了 [Shfl](https://fmhy.net/audio#curated-recommendations)，由音乐撰稿人和艺术家提供推荐，拥有庞大目录、指南、主题列表以及 [更多内容](https://i.ibb.co/jP4w9jzF/image.png) / [2](https://i.imgur.com/129i3Dk.png)。 

- 在书籍推荐中推荐了 [NPR's Books We Love](https://fmhy.net/reading#book-recommendations)，它 [汇集了数千条](https://i.imgur.com/px72ucF.png) / [2](https://i.ibb.co/Kxw7L73t/image.png) 由其数百名记者、评论员和工作人员精心挑选的推荐。

- 在 Android 图片画廊中推荐了 [Refra + Right Gallery](https://fmhy.net/mobile#image-galleries)，两者都有非常漂亮的界面、丰富的功能，并且受到了试用者的一致好评。

- 在 Minecraft 服务器托管工具中推荐了 [Crafty Controller](https://fmhy.net/gaming-tools#hosting-tools)，这是一个跨平台服务器手柄，可在浏览器中运行，支持文件上传、整合包导入等功能。

- 在 Linux 游戏中推荐了 [SLSsteam](https://fmhy.net/linux-macos#linux-gaming)，这是一个 Steam 客户端模组，带有 DLC 解锁器和模拟成就功能。

- 在多模型站点中推荐了 [Together.ai](https://fmhy.net/ai#multiple-model-sites)，每日额度不错，免费模型可靠，并支持网络搜索。

- 在网络电台中推荐了 [AccuRadio](https://fmhy.net/audio#internet-radio)，提供预设主题频道，涵盖数百种风格，无限次跳过以及[更多内容](https://i.ibb.co/6JwVfm8Q/image.png) / [2](https://i.imgur.com/ODhkBNk.png)。

- 在「音乐探索」中将 [NTS Radio](https://fmhy.net/audio#music-discovery) 标为推荐，它由拥有超过 [600 位常驻主持人](https://i.ibb.co/HDYDQWXB/image.png) / [2](https://i.imgur.com/8ckHCwU.png) 的全球社区主导，成员包括音乐人、DJ、艺术家和唱片收藏者，并配有嘉宾节目和特别节目。 

- 在 MOBA 工具中推荐了 [Rose](https://fmhy.net/gaming-tools#moba-tools)，这是 LoL 皮肤管理器 / 解锁器，使用安全，没有任何人反馈过问题，拥有游戏中的每一款皮肤（仅在你屏幕上显示）。

- 在 iOS 社交媒体中推荐了 [RyukGram](https://fmhy.net/mobile#social-media-apps-1)，这是一个积极维护的 Instagram 调整工具，试用者反馈良好，似乎是目前最佳选择。

- 在 iOS 音频中推荐了 [8SPINE](https://fmhy.net/mobile#ios-audio)，这是一个基于模块的流媒体 + 下载应用，界面漂亮，设置丰富，并支持无损播放（配合特定模块）。

- 在语言学习中推荐了 [Yomitan](https://fmhy.net/educational#multi-language)，这是一个功能丰富的浏览器弹窗词典，支持自定义主题、Anki 集成等。

- 在编程基准测试中推荐了 [DeepSWE](https://fmhy.net/ai#coding-benchmarks)，非常可靠，更新频繁，能测试模型的所有推理能力。

- 在本地 AI 前端中推荐了 [Cherry Studio](https://fmhy.net/ai#local-ai-frontends)，设置简单，界面漂亮。

- 移除了 nitter 和 xcancel，因为两者都已被 X 强制[关停](https://i.ibb.co/tjszjwK/image.png) / [2](https://i.imgur.com/j3HYkmB.png)。

- 未推荐 Netlify，因为他们不再提供 10GB / 100GB 带宽套餐，而是改用额度系统，提供的量少得多。

- 未推荐 squid(wtf)，因为它现在仅支持 KHInsider 和 JioSaavn。
