# 新增星标 ⭐ {#stars-added-⭐}

- 在 Android YouTube Music 应用中推荐了 [ArchiveTune](https://fmhy.net/mobile#youtube-music)，界面美观，对用户来说似乎运行良好。

- 在食品板块推荐了 [Too Good To Go](https://fmhy.net/misc#food)，是获取便宜食品并减少食物浪费的好方法，试用过的成员反馈良好。

- 在阅读追踪 / 数据库中推荐了 [Hardcover](https://fmhy.net/reading#tracking-database)，界面美观，功能丰富，并支持从其他平台（如 goodreads）导入。

- 在粘贴板网站中推荐了 [Yasosu](https://fmhy.net/text-tools#pastebins)，支持 markdown，允许编辑粘贴内容，并支持自定义 URL。

- 在精选推荐中推荐了 [The Criterion Closet](https://fmhy.net/video#curated-recommendations)，是 Criterion 步入式衣帽间的 3D 再现，带有筛选功能。

- 在 Linux 音频中推荐了 [LibrePods](https://fmhy.net/linux-macos#linux-audio)，让你能在 Linux（以及已 root 的 Android）上使用 AirPod 功能。

- 在动漫 BT 下载中推荐了 [SeaDex](https://fmhy.net/video#anime-torrenting)，是动漫视频画质指南，可与 Stremio + AIOStream 等搭配使用。

- 在 Linux 系统中推荐了 [LACT](https://fmhy.net/linux-macos#linux-system)，功能丰富的 GPU 配置与监控工具，简化了超频。

- 在机器学习中推荐了 [Unsloth](https://fmhy.net/ai#machine-learning)，是易于使用的微调 + AI 套件，似乎颇受欢迎。

- 在元素周期表中推荐了 [Zperiod](https://fmhy.net/educational#periodic-tables)，是简洁的互动式元素周期表，配有 3D 原子模型。

- [Bookracy](https://fmhy.net/reading#ebooks) 已恢复，并已在电子书板块重新收录、重新推荐。

- [Soft98 + DownloadHa](https://fmhy.net/downloading#software-sites) 都已恢复可用，已在软件区重新添加并重新标为推荐。
