# 新增推荐 ⭐ {#stars-added-⭐}

- 在 Android YouTube Music 应用中推荐 [ArchiveTune](https://fmhy.net/mobile#youtube-music)，UI 美观，大家似乎也用得不错。

- 在食品部分推荐 [Too Good To Go](https://fmhy.net/misc#food)，是获取廉价食物并减少食物浪费的好方法，试用过的成员反馈良好。

- 在阅读追踪 / 数据库部分推荐 [Hardcover](https://fmhy.net/reading#tracking-database)，UI 美观、功能丰富，支持从其他平台（如 goodreads）导入。

- 在 Pastebins 中推荐 [Yasosu](https://fmhy.net/text-tools#pastebins)，支持 markdown、允许编辑帖子，并支持自定义 URL。

- 在精选推荐中推荐 [The Criterion Closet](https://fmhy.net/video#curated-recommendations)，带有筛选功能的 3D Criterion 步入式衣橱复刻。

- 在 Linux 音频部分推荐 [LibrePods](https://fmhy.net/linux-macos#linux-audio)，允许在 Linux（及已 root 的 Android）上使用 AirPod 功能。

- 在动漫 BT 下载中推荐 [SeaDex](https://fmhy.net/video#anime-torrenting)，动漫视频质量指南，可与 Stremio + AIOStream 等工具配合使用。

- 在 Linux 系统部分推荐 [LACT](https://fmhy.net/linux-macos#linux-system)，功能丰富的 GPU 配置 + 监控工具，简化超频。

- 在机器学习部分推荐 [Unsloth](https://fmhy.net/ai#machine-learning)，易于使用的微调 + AI 套件，似乎广受好评。

- 在元素周期表中推荐 [Zperiod](https://fmhy.net/educational#periodic-tables)，简洁的交互式元素周期表，带有 3D 原子模型。

- [Bookracy](https://fmhy.net/reading#ebooks) 已回归，并已在电子书部分重新添加和推荐。

- [Soft98 + DownloadHa](https://fmhy.net/downloading#software-sites) 均已恢复可用，已在软件区重新添加并重新标为推荐。
