# 新增星标 ⭐ {#stars-added-⭐}

- 在动漫流媒体中推荐 [AnimeX](https://fmhy.net/video#anime-streaming)。功能丰富、源可靠、库大、UI 美观，并且有论坛。

- 在图像生成中推荐 [Bing Image Creator](https://fmhy.net/ai#image-generation)。每日 200 次额度，编辑功能好，目前似乎是使用 GPT Image 1 的最佳方式。

- 在 Android TV 中推荐 [TizenTube Cobalt](https://fmhy.net/video#android-tv)。无广告 YouTube 应用，更新频繁，支持 SponsorBlock，使用官方 YouTube UI。

- 在体育直播中推荐 [Watch Footy](https://fmhy.net/video#live-sports)。源可靠、UI 美观、赛事丰富。

- 在直播工具中推荐 [Streamer.bot](https://fmhy.net/video-tools#live-streaming)。[功能丰富](https://streamer.bot/features)的直播管理器，兼容 OBS、Streamlabs 等。

- 在 Roblox 工具中推荐 [RoSeal](https://fmhy.net/gaming-tools#roblox-tools)。改进 Roblox 网站，新增近 200 项额外功能。

- 在 Android 有声书播放器中推荐 [Voice](https://fmhy.net/mobile#android-reading)。开源、多格式、支持封面获取，极简设计美观。

- 在移动端生产力中推荐 [Loop Habit Tracker](https://fmhy.net/mobile#productivity-trackers)。开源、常驻通知，限制比大多数免费选项更宽松。

- 因回归而重新推荐 ROM 网站中的 [CDRomance](https://fmhy.net/gaming#rom-sites)。注意 RetroGamingTalk 账号可在 CDRomance 使用。

# 已移除内容 {#things-removed}

- 移除 Anadius，因其已[决定退出](https://i.ibb.co/TD9kRCR3/image.png) / [2](https://i.imgur.com/2Xk8Jor.png)。若未来有新维护者接手，可能会重新收录。

- 移除 ContextSearch，因其已被 Firefox 下架。它似乎会造成问题，某些情况下还会向网站发送大量请求。我们不确定是开发者故意作恶还是失误，但无论如何，建议将其移除并尝试 [ContextSearch web-ext](https://fmhy.net/internet-tools#firefox-extensions) 等其他选项。

- 在文件管理器中将 [文件](https://fmhy.net/file-tools#file-managers) 设为未推荐。这个项目最初被炒得很热，但现在已有人站出来表示它太卡顿、太慢，实用性不高。

- 在 [图像生成](https://fmhy.net/ai#image-generation) 中将 Grok、Qwen、Mage 和 Flux.1 Schnell 设为未推荐。这些模型过去被认为不错，但目前已有更好、更不过时的免费选择。
