大家好，新年快乐！在告别 '23 之际，让我们花点时间回顾 FMHY 这一年走过的非凡旅程：

- 我们做了一个新网站，内置了一系列手工打造的功能（当然是我做的），以提升你的体验，让浏览 wiki 在所有设备（包括移动端！）上都很舒适。
- 我们开设了 Discord 服务器，成员数达到 1 万，为社区引进了许多优秀的新人，也让贡献变得更容易。
- 我们在 Reddit 上达到了 25 万+ 成员和 3100 万次浏览！
- 我们的 FMHYedit 仓库见证了社区提交的 1000+ 个拉取请求，并合并了超过 8000 次提交！
- 这个 wiki 已不再只是一个盗版索引，所以我们觉得是时候也给其他板块一些关爱了。因此，我们整理并把工具板块拆分成了各自的页面，这让我们能把大量有用的工具从存储中移出来，也让发现它们变得容易得多。
- 我们开启了 FMHY 的瘦身阶段，链接从 2.7 万减少到 2.4 万！我们移除了大量失效、无用和小众的链接 / 分类，并重新整理了许多板块，使其更清晰、更易于导航。

迈入 2024 年，我们热切期待在已有成就之上继续发展、共同成长。没有社区里每个人的热爱与支持，FMHY 不会成为今天的样子。感谢你成为 FMHY 不可或缺的一部分。祝愿新的一年继续成长与成功！💙

### Wiki 更新 {#wiki-updates}

- 我们为 **[SearX](https://searx.fmhy.net/)** + **[Whoogle](https://whoogle.fmhy.net/)** 都搭建了自己的实例。

- 我们在自己的网站上做了一个 [帖子](/posts) 页面，无需 Reddit 就能查看所有更新。你也可以通过 [RSS](/feed.rss) 订阅。

- 为 [社交媒体工具](/social-media-tools) 创建了新分类，并为需要子板块的热门网站（Reddit、Discord、YouTube 等）添加了子板块。

- 添加了 [游戏原声带](/audio#game-soundtracks)、[IRC 工具](/downloading#irc-tools) 和 [编程 AI](/developer-tools#coding-ais) 板块。

- 将职业板块拆分为子板块：[远程工作](/misc#remote-jobs)、[技术工作](/misc#tech-jobs)、[创业](/misc#startup) 和 [金融 / 加密货币](/misc#finance-crypto)。

- 将游戏模组板块拆分为子板块：[模组索引](/gaming#mod-indexes) 和 [单个模组](/gaming#game-mods)。

- 将新闻板块拆分为子板块：[聚合器](/misc#aggregators) 和 [科技新闻](/misc#tech-news)。

- 重新整理了 [Android 操作系统](/mobile#operating-systems) + [应用启动器](/mobile#app-launchers)，并将它们从存储中移出。

### 新增星标 ⭐ {#stars-added-⭐}

- 在流媒体网站中推荐了 [Braflix](/video#streaming-sites)。流媒体速度快、无广告、界面美观，支持 4K + 1080p。

- 在阅读网站中推荐了 [Liber3](/reading#ebooks)。书库庞大、界面美观、单击即可下载。

- 在视频播放器中推荐了 [Screenbox](/video-tools#video-players)。开源、基于 VLC 的视频播放器，界面美观。

- 在 Discord 客户端中推荐了 [Vesktop](/social-media-tools#discord-clients)。基于 Vencord 构建的轻量桌面客户端。

- 在 AI聊天机器人中推荐了 [SydneyQt](/ai#proprietary-llms)。越狱版 Bing AI。

- 在 FOSS APK 中推荐了 [App Manager](/mobile#foss-apks)。开源的 Android 应用包管理器。

- 在 Android 工具中推荐了 [scrcpy](/mobile#android-device)。可通过桌面管理移动端设备。

- 在 Android 设备中推荐了 [KernelSU](/mobile#android-device)。这是一款 root 工具，有些人更喜欢用它而不是 Magisk。

- 在 iOS 隐私中推荐了 [Onion Browser](/mobile#ios-privacy)。Tor 在其网站上推荐了这款浏览器。

- 在非官方社区软件中推荐了 [Wii 指南](/gaming#homebrew)。

- 在视频工具中推荐了 [Video2x](/video-tools#video-tools-1)。无损视频/GIF/图像放大工具。

- 在 Windows 更新中推荐了 [VCRedist](/system-tools#windows-updates)。轻松下载所有 Microsoft Visual C++ 运行库。

- 在隐私扩展中推荐了 [CanvasBlocker](/privacy#privacy-extensions)。防止 JavaScript API 指纹识别。

### 已移除内容 {#things-removed}

- 移除了 SevenGamers，因为他们[决定关闭](https://i.imgur.com/C5sgVqI.png)。

- 移除了 YasDL，因为他们上传了一个带恶意软件的 StarDock 版本，filecr 和其他站点正是因此被移除的。

- 移除了 Torrentz2，因为他们已停止索引新种子。

- 未推荐 LookMovie，因为他们在视频播放前加入了[10 秒等待](https://i.imgur.com/I0D9Hyt.png)。

- 未推荐游戏工具中的 DS4Windows。你只需将游戏添加到 Steam，然后右键点击游戏并开启 PS4 手柄支持即可。

- 未推荐 Ideogram，因为它不再提供无限使用。

- 移除了 EveryNoiseAtOnce，因为开发者已被[Spotify 解雇](https://i.imgur.com/AaIrcAc.png)。

- 移除了 CryptoStorm，因为它[可能不安全](https://i.imgur.com/VDlSY1T.png)。所有者似乎已与其无关，但仍很难信任一家有着如此黑暗历史的公司。

- 从 NotABug 移除了我们的备份。他们的网站现在几乎[每天都宕机](https://i.imgur.com/Vx8Ou68.png)，在那里保持 25 个 wiki 页面更新已成噩梦。如果他们修复了问题，我们可能会恢复。
