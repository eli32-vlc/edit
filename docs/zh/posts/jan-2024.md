大家好，新年快乐！告别 '23，让我们花点时间回顾一下 FMHY 这一年走过的非凡历程：

- 我们做了一个新网站，内置了一系列手工打造的功能（当然是我做的），以提升你的体验，让在所有设备上（包括手机！）浏览 wiki 都变得舒适。
- 我们开设了 Discord 服务器，成员达到 1 万，为社区引进了许多优秀的新人，也让贡献变得容易。
- 我们在 Reddit 的成员达到 25 万+，浏览量达到 3100 万！
- 我们的 FMHYedit 仓库收到了社区提交的 1000+ 个拉取请求，合并了超过 8000 次提交！
- 这个 wiki 已经不再只是盗版索引，所以是时候让其他板块也得到一些关注了。为此，我们把工具板块整理并拆分成了独立页面，这让我们能把大量有用的工具从 storage 里移出来，也更容易发现它们。
- 我们开启了 FMHY 的瘦身行动，链接从 2.7 万降到了 2.4 万！我们移除了大量失效、无用和小众的链接 / 分类，并重新整理了诸多板块，使其更清晰、更易浏览。

迈入 2024 年，我们热切期待在已有成果的基础上继续前进，共同成长。没有社区里每个人的热爱与支持，FMHY 不会是今天的样子。感谢你成为 FMHY 不可或缺的一部分。祝愿新的一年继续成长与成功！ 💙

### 新增推荐 ⭐ {#stars-added-⭐}

- 在在线观看站点中推荐 [Braflix](/video#streaming-sites)。加载快、无广告、UI 美观，支持 4K + 1080p。

- 在阅读站点中推荐 [Liber3](/reading#ebooks)。书库庞大、UI 美观、一键下载。

- 在视频播放器中推荐 [Screenbox](/video-tools#video-players)。开源、基于 VLC 的视频播放器，UI 美观。

- 在 Discord 客户端中推荐 [Vesktop](/social-media-tools#discord-clients)。基于 Vencord 构建的轻量桌面客户端。

- 在 AI 聊天机器人中推荐 [SydneyQt](/ai#proprietary-llms)。越狱版 Bing AI。

- 在 FOSS APK 中推荐 [App Manager](/mobile#foss-apks)。开源安卓应用包管理器。

- 在安卓工具中推荐 [scrcpy](/mobile#android-device)。通过桌面管理移动设备。

- 在 Android 设备中推荐了 [KernelSU](/mobile#android-device)。这是有些人比 Magisk 更偏好的 root 工具。

- 在 iOS 隐私中推荐了 [Onion Browser](/mobile#ios-privacy)。Tor 在其网站上推荐了它。

- 在 Homebrew 中推荐了 [Wii Guide](/gaming#homebrew)。

- 在视频工具中推荐了 [Video2x](/video-tools#video-tools-1)。无损视频/GIF/图像放大工具。

- 在 Windows 更新中推荐了 [VCRedist](/system-tools#windows-updates)。轻松下载所有 Microsoft Visual C++ 运行库。

- 在隐私扩展中推荐了 [CanvasBlocker](/privacy#privacy-extensions)。防止 JavaScript API 指纹识别。

### 已移除内容 {#things-removed}

- 移除了 SevenGamers，因为他们已[决定关闭](https://i.imgur.com/C5sgVqI.png)。

- 移除了 YasDL，因为他们上传的 StarDock 版本带有与 filecr 等被移除站点相同的恶意软件。

- 移除了 Torrentz2，因为他们已停止索引新种子。

- 取消了 LookMovie 的推荐，因为他们在视频播放前添加了[10 秒等待](https://i.imgur.com/I0D9Hyt.png)。

- 取消了游戏工具中 DS4Windows 的推荐。你只需将游戏添加到 Steam，右键点击游戏即可开启 PS4 控制器支持。

- 取消了 Ideogram 的推荐，因为它不再无限使用。

- 移除了 EveryNoiseAtOnce，因为开发者已[被 Spotify 解雇](https://i.imgur.com/AaIrcAc.png)。

- 移除了 CryptoStorm，因为它[可能不安全](https://i.imgur.com/VDlSY1T.png)。所有者显然已与之无关，但仍很难信任一家有着如此黑暗历史的公司。

- 从 NotABug 移除了我们的备份。他们的网站现在几乎[每天都](https://i.imgur.com/Vx8Ou68.png)宕机，在那里维护 25 个 wiki 页面已成噩梦。如果他们修复问题，我们可能会恢复。
