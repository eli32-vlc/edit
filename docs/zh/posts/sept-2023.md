### Wiki 更新 {#wiki-updates}

- 将 Linux 工具拆分为子分类：[系统](/linux-macos/#linux-system)、[应用](/linux-macos/#linux-apps)、[网络](/linux-macos/#linux-internet)、[终端 / Shell](/linux-macos/#terminal--shell)和[自定义](/linux-macos/#customization)。

- NSFW 板块已[全面改版](/nsfwpiracy/)，新增了大量站点和分区。

- 在阅读站点中新增了 Z-Lib 的新[桌面应用 / 扩展](/reading/#reading-sites)。

- 用 [AniWave](/video/#anime-streaming)替换了 9anime，因为他们已[更名](https://torrentfreak.com/9anime-rebrands-to-aniwave-citing-legal-troubles-230802/)以避免被封锁。

- 将下载管理器中的 IDM 链接替换为[激活脚本](/storage/#file-download-managers)。

- 将侧边栏中的 /r/VPN 替换为 [r/VPNs](https://www.reddit.com/r/vpns/)，因为它允许用户讨论具体的服务商。

### 新增推荐 ⭐ {#stars-added-⭐}

- 在[在线观看站点](/video/#multi-server)中推荐了 SusFlix 和 The Movie Archive。库大、画质 4K。

- 在视频下载中推荐了 [Dhokla](/video/#drives--directories)。超大网盘、下载快速。

- 在 AI 聊天机器人中推荐了 [Awesome Free ChatGPT](https://github.com/LiLittleCat/awesome-free-chatgpt/blob/main/README_en.md)。海量免费聊天机器人列表。

- 在文件压缩工具中推荐了 [NanaZip](/storage/#compression-programs)。开源、现代设计，部分人更偏爱它而非 7-Zip。

- 在种子客户端中推荐了 [Deluge](/torrenting/#torrent-clients)。开源客户端，拥有许多实用的[插件](https://dev.deluge-torrent.org/wiki/Plugins)。

- 在 Android 音频中推荐了 [InnerTune](/mobile/#android-audio)。开源 YouTube Music 客户端。

- 在[原版 APK](/mobile/#untouched-apks)中推荐了 APKPure 和 UpToDown。

- 在[索引](/misc/#indexes)中推荐了 EverythingMoe 和 Ripped。可靠的盗版索引站。

- 在漫画中推荐了 [ReadAllComics](/reading/#comic-sites)。库大、无验证码。

- 在体育在线观看中推荐了 [WatchWrestling24](/video/#sports-streaming)。视频托管稳定、上传迅速。

- 在杀毒中推荐了 [Sandboxie Plus](/privacy/#antivirus)。易用的软件沙盒 / [指南](https://rentry.co/sandboxie-guide)。

- 在购物中推荐了 [DarkPatternsTipline](/misc/#shopping)。欺骗性服务设计举报热线。

- 在包管理器中推荐了 [Scoop](/storage/#package-managers)。Windows 命令行安装工具。

- 在文件工具中推荐了 [SA Drive](/toolsguide/#file-tools)。Google 服务账号 Drive 管理器。

- 在图像放大中推荐了 [OpenModelDB](/storage/#image-upscalers)。放大模型数据库。

- 在视频工具中推荐了 [EyeCndy](/toolsguide/#video-tools)。运镜技巧库。

### 已移除内容 {#things-removed}

- 我们已停止收录并开始移除所有需要付费 API 密钥才能运行的 AI 工具。

- 移除了 FileCR，因为他们[被查出携带恶意软件](https://rentry.co/filecr_malware)，而且至今仍未将其清除。

- 移除了 AnonFiles，因为他们因[网站遭滥用](https://i.imgur.com/lXoEqAV.png)而决定关停。

- 在 File Archivers 中取消了 WinRAR 的星标。鉴于 7-Zip / NanaZip 等开源方案，人们觉得它不再那么实用了。

- 从 ReVanced 部分移除了 RVX，因为它已[停止维护](https://github.com/inotia00/revanced-documentation/wiki/Announcement)。

- 从 PDF Sites 中移除了 PDF Drive，因为下载功能已失效。

- 从 Debloaters 中移除了 TronScript。有些人认为它[过于大动干戈](https://i.imgur.com/K5hf5Bu.png)。

- 从 AI Chatbots 中移除了 Poe，因为它现在限制为每天 10 条消息（部分国家为 100 条）。

- 从 Indexes 中移除了“Everything I Know” wiki，因为它已转为[付费](https://i.imgur.com/ig8jPGL.jpg)。你可以通过屏蔽遮罩层绕过，但我们不想再把流量引向他们。

- 取消了 1337x 的星标，并添加了[警告](https://pastebin.com/Rc9MYMZ7)以避开软件 / 游戏，因为他们曾出现恶意软件问题，包括一个在被举报后仍挂了好几天的种子。他们最终确实将其移除，并[回应](https://i.imgur.com/ij4CXIm.png)了这一情况，所以我们认为完全移除他们的网站有失公平。我们希望 1337x 今后能反应更快，避免此类情况，并随时间推移重新赢回人们的信任。
