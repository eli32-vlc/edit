# 新增推荐 ⭐ {#stars-added-⭐}

- 在官方模型中重新推荐 [Copilot](https://fmhy.net/ai#official-model-sites)，并将其移至第 2 位。它现在可无限使用 o4-mini 和 GPT-5。

- 推荐翻译器中的[DeepL](https://fmhy.net/text-tools#translators)。快速、准确，并支持灵活的后处理，非常适合生产环境。

- 推荐游戏下载中的[UnionCrax](https://fmhy.net/gaming#download-games)。拥有快速主机、预安装，并支持请求。

- 推荐 YouTube 自定义中的[VORAPIS](https://fmhy.net/social-media-tools#youtube-customization)。恢复经典布局并提升性能。

- 推荐 Wii Homebrew 中的[WiiLink](https://fmhy.net/gaming-tools#wii-u-wii-homebrew)。恢复了被任天堂放弃的 Wii Channels 功能。

- 推荐 Android APK 中的[AN1](https://fmhy.net/mobile#modded-apks)。拥有庞大的游戏库、快速更新和一键下载。

- 推荐 Android 音频播放器中的[Namida](https://fmhy.net/mobile#android-audio-players)。流畅、高度可定制、支持 YouTube，且界面美观。

- 推荐系统调整中的[StartAllBack](https://fmhy.net/system-tools#system-tweaks)。在 Win11 中恢复 Win10 风格的 UI 功能，并提升整体响应速度。

- 推荐 AI 聊天机器人中的[Z.ai](https://fmhy.net/ai)。快速、无限、表现出色；它是目前可用的较优秀的开源推理模型之一。

- 推荐浏览器模拟器中的[GAM.ONL](https://fmhy.net/gaming#browser-emulators)。拥有非常美观的界面和导航系统，以及众多主机和游戏。

- 在 PlayStation Homebrew 中推荐了 [Vita Hacks Guide](https://fmhy.net/gaming-tools#playstation-homebrew)。它广受认可、通俗易懂，对于任何开始 Vita 改机的人来说都强烈推荐。

- 在 Subtitle Tools 中推荐了 [Subtitle Edit](https://fmhy.net/video#subtitle-tools)。它是一款易于使用、功能丰富且维护良好的字幕编辑器。
