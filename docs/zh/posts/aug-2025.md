# 新增星标 ⭐ {#stars-added-⭐}

- 在歌曲识别中推荐了 [Google Assistant](https://fmhy.net/audio#song-identification)。它通过哼唱歌曲来识别；在我们的测试中似乎比 Shazam 更准确。

- 在图像生成中推荐了 [Qwen](https://fmhy.net/ai#image-generation)。无限使用，无需注册；目前似乎几乎和 4o 一样好。

- 在 Reddit 工具中推荐了 [Redlib](https://fmhy.net/social-media-tools#reddit-tools)。隐私友好的 Reddit 前端，无需账号即可使用。

- 在打字课程中推荐了 [keybr](https://fmhy.net/text-tools#typing-lessons)。自定义盲打练习，UI 美观，支持多人、个人资料、主题等。

- 在 Android YouTube 下载器中推荐了 [Seal](https://fmhy.net/mobile#android-youtube-apps)。开源下载器，支持许多网站。

- 在 Android 电池工具中推荐了 [SaverTuner](https://fmhy.net/mobile#battery-tools)。这款省电应用在我们的测试中让许多人取得了不错的效果。

- 在 Android 社交媒体中推荐了 [Xtra](https://fmhy.net/mobile#social-media-apps)。开源的 Twitch 客户端，对很多人来说似乎运行良好。

- 在直播体育中推荐了 [FSTV](https://fmhy.net/video#live-sports)。直播源速度快，覆盖的联赛数量也相当可观。

- 在音频元数据中推荐了 [MusicBrainz Picard](https://fmhy.net/audio#audio-metadata)。大型目录，适合批量元数据自动化和排序。

- 在饮品部分推荐了 [Beanconqueror](https://fmhy.net/misc#drinks)。开源、无广告且[功能丰富](https://i.ibb.co/1GkdXk4N/image.png)的冲煮记录应用。

- 在填字游戏部分推荐了 [Crosshare](https://fmhy.net/gaming#crosswords)。功能丰富、可自定义 UI，用户群活跃且每日更新谜题。

- 在计算机科学中推荐了 [CS50](https://fmhy.net/educational#computer-science)。广受推崇的哈佛计算机科学课程。

# 已移除内容 {#things-removed}

- 移除 nsw2u、nswdl、ps4pkg 和 游戏-2u，因为它们已被 FBI 针对并[关闭](https://torrentfreak.com/fbi-seizes-gaming-piracy-domains-including-pre-release-target-nsw2u/)。

- 移除了 InstallGentoo Wiki，因为它已被喷子接管。截至目前应避免访问该网站（NSFL 内容），但如果情况得到处理，我们会考虑重新添加。

- 移除了 HuggingChat，因为它已[关闭](https://x.com/julien_c/status/1940082259287069089)。请注意 HuggingFace 仍然可用；只是聊天功能已消失。

- 从 YT 下载器中移除了 Cobalt，因为它[不再支持 YouTube](https://x.com/justusecobalt/status/1943279590178230618)。请注意它仍支持其他视频网站，因此我们将其保留在适合的其他部分中。

- 移除了 Masquerade Repacks，因为它们已[宣布退出](https://i.ibb.co/0pndbGNP/image.png)；请注意 Kaos 本身仍在强劲发展。
