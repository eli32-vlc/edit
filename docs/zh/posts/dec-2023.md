### 新增星标 ⭐ {#stars-added-⭐}

- 在流媒体网站中推荐了 [Streamflix](/video#multi-server)。界面美观，1080p 速度快，由我们社区成员运营。

- 在流媒体网站中推荐了 [watch.lonelil](/video#multi-server)。界面美观，4K + 1080p 速度快，支持电视直播。

- 在游戏下载板块中推荐了 [Game Bounty](/gaming#download-games)。下载主机速度快，提供预安装版本，上传内容干净，由我们社区成员运营。

- 在废弃软件游戏板块中推荐了 [AbandonwareGames](/storage#abandonware-games)。网站不错，拥有庞大的复古游戏库。

- 在 Steam / Epic 中推荐了 [Heroic Games Launcher](/gaming#steam-epic)。开源 Epic 游戏启动器。

- 在下载目录中推荐了 [TG Archive](/downloading#download-directories)。Telegram 文件归档 + 搜索工具。

- 在系统精简中推荐了 [BleachBit](/system-tools#system-debloating)。流行的系统文件清理工具。

- 在 YouTube 下载中推荐了 [YT-DLP-GUI](/video-tools#youtube-download)。YT-DL 的美观 GUI，带一键安装程序。

- 在系统调整中推荐了 [EverythingToolbar](/system-tools#system-tweaks)。为 Windows 工具栏添加许多功能。

- 在翻译器中推荐了 [DeepL](/text-tools#translators)。大家觉得它给出的结果数一数二。

- 在游戏优化中推荐了 [Magpie](/gaming#optimization-tools)。在任何游戏或设备上启用 AMD FSR。

- 在 iOS 应用中推荐了 [TrollStore](/mobile#ios-apps)。无需 PC、付费开发者账户或越狱即可永久安装非 App Store 的 iOS 应用。 

- 在智能电视 / Firestick 中推荐了 [SmartTube](/video#smart-tv-firestick)。无广告 YouTube 应用。以前称为 SmartTubeNext。

### 已移除内容 {#things-removed}

- 移除了 NovaAI，因为他们[决定关闭](https://www.reddit.com/r/Piracy/comments/17pzrzj/nova_oss_the_api_that_provided_free_gpt4_and/)。

- 移除 LocalCDN 和 Decentraleyes，因为在启用 [Total Cookie Protection](https://blog.privacyguides.org/2021/12/01/firefox-privacy-2021-update/#localcdn-and-decentraleyes) 后它们显得多余。

- 将所有 CurseForge 链接替换为 Modrinth，因为用户觉得 CurseForge [不太配合](https://youtu.be/Vhdwz5apiQQ?si=xgzkQFa1S7hZNa5-)其用户群体。

- 未推荐 12ft.io，因为它已无法绕过基于非 JavaScript 的付费墙。

- 移除 FileListing，因为其服务器已关闭。

- 移除 GreaseMonkey，因为它已 3 年未更新，且可能有过跟踪用户的历史。
