### 新增推荐 ⭐ {#stars-added-⭐}

- 推荐在线观看网站中的 [Streamflix](/video#multi-server)。界面美观，1080p 加载快，由我们社区的成员运营。

- 推荐在线观看网站中的 [watch.lonelil](/video#multi-server)。界面美观，4K + 1080p 加载快，支持电视直播。

- 推荐游戏下载中的 [Game Bounty](/gaming#download-games)。主机速度快，提供预安装，上传干净，由我们社区的成员运营。

- 推荐 Abandonware 游戏中的 [AbandonwareGames](/storage#abandonware-games)。网站不错，收录了大量老派游戏。

- 推荐 Steam / Epic 中的 [Heroic Games Launcher](/gaming#steam-epic)。开源 Epic Games 启动器。

- 推荐下载目录中的 [TG Archive](/downloading#download-directories)。Telegram 文件归档 + 搜索工具。

- 推荐系统精简中的 [BleachBit](/system-tools#system-debloating)。流行的系统文件清理工具。

- 推荐 YouTube 下载中的 [YT-DLP-GUI](/video-tools#youtube-download)。YT-DL 的精美 GUI，附带一键安装程序。

- 推荐系统调整中的 [EverythingToolbar](/system-tools#system-tweaks)。为 Windows 工具栏添加大量功能。

- 推荐翻译工具中的 [DeepL](/text-tools#translators)。大家认为它的翻译效果数一数二。

- 推荐游戏优化中的 [Magpie](/gaming#optimization-tools)。可在任何游戏或设备上启用 AMD FSR。

- 推荐 iOS 应用中的 [TrollStore](/mobile#ios-apps)。无需电脑、付费开发者账号或越狱，即可永久安装非 App Store 的 iOS 应用。 

- 推荐智能电视 / Firestick 中的 [SmartTube](/video#smart-tv-firestick)。无广告 YouTube 应用。原名 SmartTubeNext。

### 已移除内容 {#things-removed}

- 移除 NovaAI，因为他们 [决定关停](https://www.reddit.com/r/Piracy/comments/17pzrzj/nova_oss_the_api_that_provided_free_gpt4_and/)。

- 移除了 LocalCDN 和 Decentraleyes，因为在启用 [Total Cookie Protection](https://blog.privacyguides.org/2021/12/01/firefox-privacy-2021-update/#localcdn-and-decentraleyes) 后它们已属冗余。

- 将所有 CurseForge 链接替换为 Modrinth，因为人们觉得 CurseForge 与其用户群体[配合不佳](https://youtu.be/Vhdwz5apiQQ?si=xgzkQFa1S7hZNa5-)。

- 取消星标 12ft.io，因为它已无法绕过不基于 JavaScript 的付费墙。

- 移除了 FileListing，因为其已关闭服务器。

- 移除了 GreaseMonkey，因为它已 3 年未更新，且可能有追踪用户的历史。
