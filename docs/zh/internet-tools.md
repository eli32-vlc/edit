### 电子邮件别名 {#email-aliasing}

::: tip 提示
部分网站提供 **catch-all** 别名，如 @username.anonaddy.com，这类别名技术上无限可用，因为 @ 前的任意内容都会重定向到你的转发地址，但该别名包含一个唯一子域名，可能与你的身份关联。为了更好的隐私，请优先使用 **shared** 别名，如 x481n904@anonaddy.me，这类别名通常随机生成，且域名由网站所有用户共享，因此更难与你的身份关联。
:::
