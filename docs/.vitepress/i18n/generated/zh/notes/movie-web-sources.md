#### 向 P-Stream（以及所有 movie-web 分支）添加源

你可以启用一个扩展：[Firefox](https://addons.mozilla.org/firefox/addon/p-stream-extension-v1/) / [Chrome](https://chromewebstore.google.com/detail/p-stream-enchanced/geimjiobahmbkmaigaafjnoanebpmlmj) / [脚本](https://github.com/xp-technologies-dev/userscript)，它会添加更多源，但需要连接所有网站才能正常工作。该扩展是安全的，很多人都在用，这些权限只是为了扩展正常运行才需要的。

请注意，如果你不想使用主浏览器，可以在新浏览器或全新的浏览器配置文件中运行它。
