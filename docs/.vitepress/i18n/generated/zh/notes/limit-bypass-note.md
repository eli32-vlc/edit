#### 绕过限制说明

使用免费 Apple Account 时，Apple 仅允许侧载 3 个应用（含 SideStore）。若要在 SideStore 上绕过这一限制，可使用 [SparseBox](https://docs.sidestore.io/docs/advanced/alternative#sidestore-exploits) / [指南](https://docs.sidestore.io/docs/advanced/alternative#sidestore-exploits)（iOS 17.0 - 18.1 Beta 4，不含 17.7.1、17.7.2），或 [LiveContainer](https://github.com/LiveContainer/LiveContainer) / [2](https://github.com/LiveContainerMirror/LiveContainer/)（iOS 16+）。
