#### FreeGOGPCGames 说明

文件校验和可能与原始 GOG 安装程序不一致。这是因为该网站上的许多游戏都是较旧版本的安装程序，旧安装程序上的数字签名由 *GOG Limited* 签发，这是该公司与 *GOG Sp. z o.o* 合并前的旧名称，之后所有数字文件签名都已更新以反映这一名称变更。哈希与 gog-games 数据库不匹配的原因是安装程序上的数字文件签名不同。由于游戏版本保持不变，安装任一版本都会生成完全相同的文件集。
