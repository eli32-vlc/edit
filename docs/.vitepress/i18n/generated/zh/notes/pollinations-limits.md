#### Pollinations 限制

对于聊天功能的 chat.pollinations.ai（及其底层 API），速率限制取决于你的使用方式：

**匿名 / 免费档（无需登录）**
- **文本/聊天**：约每 **3 秒** 1 次请求（按 IP）。
- **图片**：约每 **5 秒** 1 次请求（按 IP）。

**已登录（Pollen 系统）**
- 用户会根据其档位获得 **每日免费 Pollen 额度**。
- **可发布密钥（`pk_`）**：受速率限制以防止滥用（例如每个 IP 约 1 pollen/小时）。
- **私密密钥（`sk_`）**：**无速率限制**（请求速度取决于你能用 Pollen 支付多少）。

如果你在聊天网站上遇到限制：
1. 稍微放慢速度（在消息之间等待 3-5 秒）。
2. 在 [enter.pollinations.ai](https://enter.pollinations.ai) **登录**以使用你的每日免费额度。
3. 如果你需要超高的吞吐量，请使用已购买额度的 API 密钥（`sk_`）。
